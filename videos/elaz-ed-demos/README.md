# Команда открывает праздник

Готовая Remotion-композиция ElazEdEmployeesDemo: 60 секунд, 1080 × 1920, 30 fps.
Демо для HR и внутренних коммуникаций: адвент, знания, игры, корпоратив, постоянное пространство команды и разработка под компанию.

## Запуск

Из этой папки: npm install, затем npm run dev -- --port 3005.
Открыть http://localhost:3005/ElazEdEmployeesDemo.
Восемь отдельных сцен доступны в папке Scenes. Те же компоненты связаны с основным таймлайном.

## Сцены

| Время | Содержание |
| --- | --- |
| 0–5 | Команда в Telegram |
| 5–12 | Адвент и открытие подарка |
| 12–21 | История компании и викторина |
| 21–29 | Игры, скретч и личный рейтинг |
| 29–36 | Корпоратив и подарки |
| 36–44 | Новости, адаптация и курс |
| 44–53 | Бренд, разделы, кампания, пример аналитики |
| 53–60 | Предложение и контакт @elazart |

## Редактирование

Основные параметры находятся в defaultProps в src/Root.tsx: brandName, accentColor, contact, musicVolume и voiceoverSrc.
Анимация зависит только от кадра. Каждый эпизод вынесен в src/scenes и доступен для редактирования в Studio.
Компания «Орбита», участники и статистика вымышлены. Аналитика помечена «Пример данных».

## Звук

Оригинальная инструментальная дорожка и три эффекта созданы локально: scripts/make-audio.mjs.
Версия играет с музыкой и экранным текстом. Записанного голоса нет; дикторский текст сохранён в STORYBOARD.md.
Для озвучки положите аудио в public/audio, укажите voiceoverSrc: 'audio/voiceover.wav'. Музыка автоматически станет тише.
Шрифты Onest и Unbounded хранятся локально вместе с лицензиями в public/fonts.
