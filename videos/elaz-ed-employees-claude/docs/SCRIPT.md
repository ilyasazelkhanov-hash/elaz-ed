# ElazEdEmployeesDemo — «Команда открывает праздник»

Вертикальный ролик Elaz Ed для HR, внутренних коммуникаций и организаторов корпоративов.
**60 с · 1080×1920 · 30 fps · 1800 кадров · русский язык.**

Главная мысль: начните с корпоративного события, продолжайте общение и обучение круглый год.
Компания «Орбита», сотрудники и данные вымышлены. Брендированные экраны показывают возможную адаптацию,
это не кейс существующего внедрения. В ролике нет процентов, сроков, цен и отзывов.

## Раскадровка

1. **Хук.** Карточки «Сотрудники», «Новости», «Корпоратив» хаотично кружат вокруг окна Telegram, собираются
   на орбите и сливаются в один брендированный вход «Орбиты» с кнопкой-дверью «Открыть». Палец нажимает — дверь вспыхивает.
2. **Адвент.** Приложение раскрывается из двери: «Вместе до Нового года», гирлянда, двери 1–12 (1–6 открыты, 8–12 «скоро»).
   Именная карточка «Алина — открывает день 7». Касание двери №7: дверь выезжает в центр, створки расходятся,
   крышка коробки слетает, искры и тёплый свет заливают кадр. **Первый эмоциональный пик.**
3. **Знакомство и участие.** Свет рассеивается — за дверью карточка знания той же арочной формы: «Как появилась „Орбита“».
   Затем квиз «Что мы ценим в работе с клиентами?» → выбран ответ «Помогаем решить задачу», +30 XP летит в шапку,
   тост «Новая ачивка: Знаток „Орбиты“». Сбоку — «Марат тоже прошёл день 7» (общий контекст без командного зачёта).
   Слова надписи выходят в такт: «Узнать» — история, «Попробовать» — квиз, «Поучаствовать» — XP и коллега.
4. **Игры.** Аркада «Поймай подарки» (сани, падающие подарки, серия ×2), скретч-карта «Сотри пальцем» → +50 XP,
   «8 дней подряд — новый день отмечен», личный рейтинг «Свой прогресс и немного азарта» (Алина поднимается на 2-е место)
   и ачивка «Неделя в календаре».
5. **Событие.** Новость «Встречаемся на корпоративе» в ленте раскрывается в обычный материал с программой вечера.
   Следом окно «Адвент · розыгрыш — Подарки участникам»: «Набор от компании», «Розыгрыш · Всего 20 · 1 дверь = 1 шанс»,
   «Ваши шансы» (7 дверей) и подпись «По правилам кампании».
6. **После Нового года.** Снег растворяется, гирлянда гаснет, подарки уходят. Шапка «Вместе до Нового года» становится
   «Пространство команды — открыто круглый год», подарок сменяется дверью, которая открывается в холодный дневной свет.
   Появляются «Новости команды», «Добро пожаловать в компанию», «Курс по продукту». Курс из пяти последовательных уроков
   отмечается по одному → «Вводный модуль пройден». **Второй эмоциональный пик.**
7. **Настройки.** Окно сжимается в превью, снизу выезжает панель из пяти шагов. Перекраска — отдельный эпизод:
   бренд «снимается» волной до шаблона Elaz Ed, затем после касания палитры «Орбиты» волна возвращает логотип и цвета.
   Далее: набор разделов (переключатели, превью собирает список), даты календаря «1–24 декабря», задания и призы
   (день 7 — квиз, приз с лимитом, четыре режима выдачи: За N дверей / Подарок дней / Случайный / Розыгрыш),
   статистика с меткой «Пример данных». Темп здесь спокойнее.
8. **Финал.** «Новый год», «Корпоратив», «На постоянку» собираются в карточку «Орбиты» с дверью света.
   «Соберём приложение для вашей команды», золотая кнопка «Напишите @elazart: КОМАНДА», подпись Elaz Ed авророй —
   «разработка Telegram Mini Apps» и сноска «„Орбита“ — вымышленный пример адаптации».

Что в ролике — существующие механики Elaz Ed: контент и лента, курсы с последовательными уроками, квизы с XP,
ачивки, стрик, личный рейтинг, адвент с дверями по дням, аркада и скретч, призы с лимитом, четыре режима выдачи,
редакторы контента и календаря, статистика. Что изображает работу разработки: брендирование под заказчика
(логотип, палитра, название) и подбор разделов. Командный зачёт подразделений, HR-интеграции и вход только
для сотрудников в ролике не показаны.

## Текст диктора (для записи)

Тон уверенный, тёплый, конкретный, на «вы». Темп естественный, без рекламного нажима. Паузы — по границам сцен.
Хронометраж рассчитан на ~2,3 слова в секунду; реплику 7 можно читать чуть плотнее.

| № | Старт | Окно | Реплика |
| --- | --- | --- | --- |
| 1 | 00:00,5 | 4,5 с | Ваша команда уже в Telegram. Дайте ей повод собраться. |
| 2 | 00:05,3 | 6,5 с | Создадим корпоративное приложение: с вашим брендом, новогодним адвентом и заданиями на каждый день. |
| 3 | 00:12,3 | 8,5 с | Короткие истории компании, полезные уроки и квизы помогают знакомиться с продуктом и включаться в общую жизнь. |
| 4 | 00:21,3 | 7,5 с | Добавим игры, личный рейтинг и награды. Появится маленький повод зайти снова и поучаствовать. |
| 5 | 00:29,3 | 6,5 с | До корпоратива — задания и новости. К празднику — подарки и розыгрыши с понятными правилами. |
| 6 | 00:36,5 | 7,3 с | А после праздника пространство останется: новости, вводные материалы для новичков и обучение сотрудников круглый год. |
| 7 | 00:44,3 | 8,5 с | Разработаем под вашу компанию: оформление, разделы, задания и призы. У команды будет своё пространство, у организаторов — управление и статистика. |
| 8 | 00:53,3 | 6,5 с | К Новому году, корпоративу или на постоянку. Напишите «Команда» — обсудим приложение для ваших сотрудников. |

Ударения и произношение: «Орбита» не звучит в тексте; «корпоратив» — без иронии; «на постоянку» — разговорно, легко.

**Как подключить запись:** положите один файл на всю минуту в `public/audio/voice.wav` (или `.mp3`) и в Studio
на панели Props задайте `voiceSrc: "audio/voice.wav"`. Музыка автоматически опустится до `musicVolumeUnderVoice`.
Подстрочники под заголовками при этом можно выключить: `showSublines: false`.

## Звук

Записи диктора в проекте нет — ролик собран как **экранная версия**: все смыслы читаются по надписям и подстрочникам.

Музыка и UI-звуки синтезированы скриптом `scripts/make-audio.mjs` (оригинальные, без сторонних сэмплов, детерминированные):

- `music.wav` — спокойная электроника, 100 BPM, фа мажор, мягкий пэд, бас, бочка, шейкер и зимние FM-колокольчики.
  Форма следует сценам: вступление без ритма → пульс → игры (плотнее колокольчики) → после праздника (светлее)
  → настройки (половинный темп, спокойнее) → финал с разрешением на тонику и затуханием.
- `tap.wav` — мягкое касание; `gift.wav` — тёплый акцент открытия подарка; `reward.wav` — двухнотный звон награды;
  `whoosh.wav` — тихий пролёт при смене экрана; `brand.wav` — стеклянный аккорд перекраски и входа в пространство.

Где стоят эффекты — `src/employees/sound.ts` (16 меток, кадры считаются от начала сцены).
Чтобы заменить музыку на лицензированный трек, положите файл в `public/audio/` и укажите его в `musicSrc`.

## Параметры (`src/employees/props.ts`, панель Props в Studio)

Название и подпись компании, палитра бренда и палитра шаблона, люди (Алина, Марат, участники рейтинга),
адвент (заголовок, дверь дня, число дверей, даты), история, квиз (вопрос, ответы, верный, XP), ачивка,
новость о событии и программа, приз (название, подпись, лимит), разделы постоянного пространства и уроки курса,
контакт и кодовое слово, файлы голоса, музыки и эффектов, громкости, подстрочники.

## Команды

```bash
npm install          # один раз
npm run dev          # Remotion Studio
npm run audio        # пересобрать музыку и звуки
npm run stills       # контрольные кадры + прогон всех 1800 кадров → out/check/
npm run render       # MP4 → out/ElazEdEmployeesDemo.mp4 (по отдельному запросу)
```
