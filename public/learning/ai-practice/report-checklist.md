# Проверка отчёта

- [ ] Указаны файл, период, единицы и число строк.
- [ ] Пропуски отделены от нулей.
- [ ] Формула записана явно: расходы / регистрации.
- [ ] Нулевой знаменатель помечен «не определено».
- [ ] Общий итог рассчитан по суммам, а не среднему коэффициентов.
- [ ] Для учебного campaign-results.csv: 60000 KZT, 60 регистраций, 1000 KZT/регистрацию.
- [ ] Факты отделены от гипотез; прибыль не подменена выручкой.
- [ ] Рекомендация является проверяемым экспериментом, а не гарантией.
