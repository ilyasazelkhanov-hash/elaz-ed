# Приёмка учебной страницы

- [ ] index.html открывается в браузере.
- [ ] Тема, дата и часовой пояс совпадают с brief.md.
- [ ] Пустое имя вызывает понятную ошибку рядом с полем.
- [ ] Имя из пробелов также вызывает ошибку.
- [ ] Обычное имя даёт сообщение только о локальной проверке.
- [ ] Ничего не отправляется на сервер; это явно указано.
- [ ] На ширине 320 и 390 px доступны поле, кнопка и текст ошибки.
- [ ] Сохранены исходная версия и инструкция открытия.
- [ ] Для настоящей публикации отдельно описаны сервер, хранение и проверка отправки.

Для каждого пункта запиши результат фактической проверки, дату и версию файла.
