# Адвент-календарь

24 двери до Нового года: каждый день открывается одна. За дверью квиз, скретч-карта, аркада «Поймай подарки» или короткая история. За 3, 7, 14 и 24 открытые двери человек получает код награды, который гасит кассир на отдельной странице.

Всё, что даёт XP и награды, считает сервер. Правильные ответы, приз скретча и текст двери приходят только после открытия; будущие двери не отдаются даже по прямому запросу. Счёт аркады присылает клиент, поэтому он упирается в потолок двери (`arcade.cap`): накрутка даёт не больше `cap / 2` XP и не влияет на награды — награды считаются по числу открытых дверей.

## Правила

| Что | Как |
| --- | --- |
| Дверь дня | Открывается в 00:00 по поясу кампании (`settings.advent.tz`, 300 = Алматы) — у всех одновременно |
| XP | База двери + 10 за верный ответ квиза или половина очков аркады (до потолка) |
| Пропущенная дверь | Можно догнать до конца кампании + `grace` дней, XP вполовину |
| Серия | Дни подряд, когда дверь открыта в свой день |
| Награда | Код за N открытых дверей, один на человека и ступень; `stock` ограничивает общее число кодов |
| Код | 8 символов без похожих букв (0/O, 1/I/L), приходит в календарь и в чат с ботом |
| Погашение | Только из статуса «выдан», повторно не сработает; кассир вводит PIN точки |
| PIN | 8 неверных попыток — точка блокируется на 15 минут |

Формулы продублированы в `src/lib/advent.ts` и в Edge Function (`doorXp`, `adventStreak`) — менять в обоих местах.

## Запуск

1. Применить миграции `008_user_tz_rating.sql` и `009_advent.sql`, задеплоить функцию `api` (как и раньше, без проверки JWT).
2. Наполнить двери и награды: правка в `src/lib/adventSeed.json`, затем

   ```bash
   node content/advent/build.mjs > content/advent/seed.sql
   ```

   и выполнить `seed.sql` в SQL-редакторе. Скрипт проверяет, что у квизов верный индекс ответа, у скретча есть приз и дни не повторяются. Тот же файл питает демо-режим.
3. Добавить точки погашения. PIN хранится как SHA-256 от `<id>:<pin>`:

   ```sql
   insert into public.advent_points (name, pin_hash) values ('Касса 1', '');
   update public.advent_points set pin_hash = encode(sha256(convert_to(id::text || ':482913', 'utf8')), 'hex') where name = 'Касса 1';
   ```

4. Включить календарь:

   ```sql
   update public.settings
     set value = value || '{"enabled": true, "title": "Адвент вайбкодера", "start": "2026-12-08", "days": 24}'::jsonb
     where key = 'advent';
   ```

   До даты старта на главной висит баннер «Скоро открытие». Через `days + grace` дней после старта баннер исчезает сам.
5. Ежедневное напоминание о новой двери. Нужны расширения `pg_cron` и `pg_net` (Supabase → Database → Extensions). 05:00 UTC = 10:00 в Алматы:

   ```sql
   select cron.schedule('advent-push', '0 5 * * *', $$
     select net.http_post(
       url := 'https://<проект>.supabase.co/functions/v1/api/advent_push',
       headers := jsonb_build_object('Content-Type', 'application/json',
         'x-cron-key', (select value #>> '{}' from public.settings where key = 'cron_key')),
       body := '{}'::jsonb
     );
   $$);
   ```

   Рассылка идёт в фоне по 25 сообщений в секунду, не больше 3000 человек за запуск, и пропускает тех, кто уже открыл дверь. Повторный вызов в тот же день ничего не шлёт. Сообщение дойдёт только тем, кто хоть раз писал боту или нажимал /start.
6. Страница кассира: `https://<app_url>/?redeem`. Открывается в обычном браузере на телефоне или планшете кассира; точка и PIN запоминаются до закрытия вкладки.

## Демо

`/?demo` — календарь «идёт седьмой день»: шесть дверей можно догнать, седьмая сегодняшняя. Касса: `/?redeem&demo`, PIN `1234`. Код для проверки появится после трёх открытых дверей.

## Билеты «догнать» и призы (миграция 010)

Пропущенную дверь можно открыть только за билет — за половину XP, серия не растёт. Один билет — одна дверь. Билеты выдаёт сервер, каждое действие засчитывается один раз:

| Способ | Что проверяется |
| --- | --- |
| Урок с квизом без ошибок | Запись прохождения со всеми верными ответами, сделанная после старта календаря |
| Приглашённый друг | Друг пришёл по ссылке после старта и прошёл проверку подписки на канал |
| Сторис | По ссылке из сторис (`st<id>`) зашёл другой подписчик. Не больше 5 билетов на человека |
| Звёзды | Telegram подтвердил оплату. Возврат звёзд отзывает билет, если он ещё не потрачен |

Способы и цену билета включает админ: Админка → Адвент → «Календарь». Там же число дней, название, дата старта и включение.

Призы правятся в Админка → Адвент → «Призы». Виды: промокод (уникальный код каждому, погашение на `/?redeem`, видно где и когда), сообщение, ссылка, видео, урок закрытого курса, курс целиком. Содержимое приза приходит в приложение только после выдачи. Выданный приз удалить нельзя — поставь лимит 0.
