# Creator Vault · 26 октября 2026

Обновление рабочего адвента OG CRE8R². Мастер, демонстрационный seed и новостная лента не меняются.

## Состав

- 24 сценария с конкретным заданием, артефактом и критериями результата. Импорт обновляет только ещё никем не открытые двери: при публикации обновлены 20 дверей, четыре уже открытые сохранены целиком. Условия проверяются непосредственно в транзакции, поэтому новые открытия во время подготовки учитываются.
- 11 подготовленных наград: улучшение уже существующего промпт-пака ID 9 и 10 дополнительных. После импорта всего 14 наград, включая прежний закрытый урок и два действующих режима выдачи полного курса.
- Prompt Lab, Creator Kit, Code Kit, Visual Kit, Workflow Kit, Editorial Kit, Budget & Handoff, Release Kit и Production Sprint. Внутри готовые задания с конкретным вводом, выходом и проверкой, без вымышленных ролей и стажа.
- Дополнительный настоящий закрытый урок про сториборд ищется по названию и курсу. Существующие мгновенный приз полного курса (лимит 2) и розыгрыш (лимит 3), их коды и права доступа сохраняются.
- Радар пяти официальных программ: ChatGPT для подходящих студентов США, GitHub Copilot Student, Perplexity Education, Google AI для студентов и Hugging Face ZeroGPU. Есть условия, ссылки и дата среза. Акция ChatGPT имеет явный дедлайн 31.10.2026, после которого без новой проверки считается истёкшей. Это подборка условий, не обещание подписки каждому.
- Шесть самостоятельных Telegram-постов: проверка фактов, предметный визуал, контракт исправления бага, радар выгод, стоимость результата, передача проекта. Их нет в `lessons` и ленте приложения.

## Файлы и команды

`catalog.mjs` — редактируемые материалы; `build.mjs` — сборка и проверки структуры; `payload.json` — полный пакет; `import.sql` — добавляющий импорт с сохранением прогресса и маркером `advent_premium:2026-10-26-v1`; `telegram-only.md` и `telegram-only.sql` — отдельная редакционная серия.

```powershell
node content/advent/premium-2026-10-26/build.mjs
npm run test:advent-premium
npm run test:api
npm run test:news
npm run build
```

Импорт идемпотентный. Открытые двери, выданные коды, XP, старт кампании, лимиты действующих курсовых призов и лента не сбрасываются. Обновлённый текст приза ID 9 становится доступен и его прежнему получателю, без выдачи второго кода.

Для публикации серии: сначала импортировать `telegram-only.sql` в `settings`, затем защищённый POST к `news-publisher` с телом `{"mode":"editorial","batch":"club-lab-2026-10-26"}` и существующим `x-cron-key`. Назначение берётся из `news_publishing`, не из запроса. Служебные квитанции `telegram_delivery:<chat>:<batch>:<post>` не позволяют повторить отправку при повторном запросе. Неопределённая доставка останавливает серию до ручной сверки; не сбрасывать такие квитанции вслепую.

Будущие новости продолжают публиковаться существующим минутным заданием `og-news-autopublish`. Редакционная серия не превращается в новости миниаппки и не получает ложных ссылок на несуществующие статьи.
