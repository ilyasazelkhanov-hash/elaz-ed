# Лаборатория AU-201 / AU-301

Нужен Node.js 24. Внешних зависимостей нет.

```bash
node --test integration.test.mjs queue.test.mjs cost.test.mjs
node server.mjs
```

Откройте локальный порт 5191. PORT задаёт другой порт. Все HTTP-запросы идут только к этому учебному серверу. Токен `training-only` — известный маркер протокольного примера, а не рабочая защита. Внешние CRM, почта, Telegram, OAuth и модели не вызываются.

Сценарии показывают 401 без повтора, 429 с Retry-After, временный 500, остановку таймаутов, пагинацию, нормализацию и очередь. `logicalWaitsMs` содержит рассчитанные задержки, но браузерная демонстрация их не ждёт. Это не бенчмарк поставщика.

`queue.mjs` содержит SQLite-очередь с устойчивым ID, lease и номером попытки. Для повторения сохранности используйте отдельный путь к файлу в `new JobQueue(path)`. Браузерный сценарий создаёт новую очередь в памяти при каждом запуске; он не хранит рабочие задачи между запросами. В тестах отдельно проверен постоянный файл и два соединения.

Текущая попытка передаёт свой номер в `ack` и `fail`; запоздалый результат прежней попытки отклоняется. Локальная дедупликация не гарантирует ровно один внешний эффект. Настоящая отправка требует отдельного контракта получателя и разрешённого доступа.

`CircuitBreaker` — локальная модель одного процесса. `cost.mjs` и `fictional-budget.json` используют вымышленные тарифы, не относящиеся к поставщику. Системы ролей, внешний worker доставки, распределённый кластер и backup не реализованы и не заявляются проверенными.
