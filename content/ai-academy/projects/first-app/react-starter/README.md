# Чистый учебный React/Vite-проект · VC-101

Это начальный каркас для собственной работы, а не готовая итоговая работа. Проверенный пример поведения — в родительской папке first-app; он сделан без React и запускается отдельно. Здесь ты реализуешь свою версию на React по заданиям курса.

Нужен Node.js 24 и интернет для первого скачивания закреплённых зависимостей. Открой терминал в этой папке, где лежат package.json и package-lock.json:

```bash
node --version
npm ci
npm run dev
```

Открой http://127.0.0.1:8767/. После изменения src/App.jsx обнови страницу. Если работаешь через AI-редактор, укажи ему эту папку и сначала попроси назвать изменяемые файлы. Для остановки сервера нажми Ctrl+C.

- src/App.jsx — компоненты, состояние и обработчики, которые ты добавишь сам.
- src/style.css — вид страницы и мобильная раскладка.
- src/main.jsx — подключение React к странице.
- package.json — существующие команды; lockfile закрепляет версии.

Проверка сборки:

```bash
npm run build
npm run preview
```

Сборка создаёт dist, просмотр открывается на http://127.0.0.1:8768/. Успешная сборка подтверждает сборку кода. Выбор услуги, ошибки формы и сохранение нужно отдельно проверить в браузере. Не добавляй настоящие контакты, токены или платёжные действия в учебный frontend.

Первый маленький шаг: замени заголовок в App.jsx, запусти build и сверь изменение в браузере. Затем двигайся к каталогу и одному выбранному состоянию. Сохраняй собственные наблюдения; готовая папка не даёт зачёт.
