# Design lab · DS-101 / DS-201 / DS-301

Пять работающих экранов вымышленной мастерской: объяснение → услуга → описание → review → учебный итог. Настоящая заявка не отправляется, данные формы остаются в памяти вкладки. Используй вымышленные контакты. Фото необязательно; в прототипе сохраняется его имя, серверной загрузки нет.

```bash
python3 -m http.server 5195 --bind 127.0.0.1
```

Открой `http://127.0.0.1:5195`. Вариант B по умолчанию называет переход «Проверить заявку»; `/?variant=a` показывает «Продолжить». Разница является гипотезой понятности, а не доказанным улучшением. Три заметки в research-notes.json синтетические; они не заменяют добровольные пользовательские сессии. События интерфейса записываются только после явного включения и только в память вкладки, без внешней отправки.

Node.js 24, без сторонних зависимостей:

```bash
node --test design.test.mjs
node build-tokens.mjs
node agent-eval.mjs
node compare.mjs screenshots/review-390.png screenshots/review-repeat-390.png
```

Последнее сравнение даёт ноль изменённых пикселей. Сравнение details-a-390.png и details-b-390.png намеренно обнаруживает изменение: его нужно разобрать и принять по задаче. Зелёный результат не является целью сам по себе.

research.mjs исключает внутренние записи до создания контекста и проверяет точное наличие цитат. Это не проверка корректности интерпретации. quality.mjs проверяет связь предложения аудита с измеренным провалом, считает TP/FP/TN/FN и отклоняет устаревшее evidence. В agent-eval.mjs используются шесть авторских макетов предложений; идеальный score валидатора не является оценкой живой модели. LLM/vision API не подключён, автоматического редактирования или выпуска продукта нет.

pixels.mjs сравнивает пиксели PNG RGB/RGBA 8-bit без interlace, проверяет CRC и ограничивает размер. Другие типы PNG не поддерживаются. Метаданные не создают ложного diff. Маски допускаются суммарно не более чем для 10% области; решение об их применении требует обоснования. Это учебный компаратор, не универсальная библиотека изображений.

Скриншоты уже включены. Необязательная пересборка использует отдельный lockfile, Playwright 1.62.1 и системный Chromium:

```bash
npm ci --ignore-scripts
node capture.mjs
```

По умолчанию браузер `/usr/bin/chromium`, другой путь задаётся через `CHROMIUM_BIN`. Проверяется реальный браузерный путь: ошибки и исправление, сохранение значений, keyboard-confirm, отсутствие горизонтального переполнения на 320/390/1024 px и точное совпадение повторных снимков. capture-report.json содержит границы этой проверки. Она не является реальным usability-test или сертификацией WCAG.
