# Учебный конвейер разработки

Это подготовленная лаборатория для следующих курсов ENG-201/ENG-301. Материалы этих курсов подключены к локальному каталогу.

Node.js 24, без внешних зависимостей:

```bash
node --test harness.test.mjs
node demo.mjs
```

Демонстрация копирует starter во временную папку, выполняет три разрешённых шага, применяет заранее проверенную правку и запускает семь проверок. Повтор читает checkpoint и не добавляет новые записи аудита. Внутренний дочерний test runner запускается независимо от NODE_TEST_CONTEXT родительского теста.

Исходная subtotal готова и имеет три baseline-теста. Feature-тесты намеренно описывают ещё не добавленную withFee; они проходят после шага apply_reviewed_patch. Запуск только baseline из starter: `node --test test/base.test.mjs`. Все семь проверок после правки запускает harness.

Роли, число шагов, timeout, пути и символические ссылки проверяются отдельно. Файл CANCEL останавливает следующие шаги. Изменённый план не продолжает старый checkpoint незаметно. Одновременный запуск нескольких процессов на одном checkpoint не поддерживается.

Настоящая coding-модель не вызывается. Разрешённая правка заранее задана автором, произвольная команда не принимается. Эти ограничения не являются изоляцией ОС: обычный Node-процесс имеет полномочия своего пользователя. Не запускайте неподтверждённый код рядом с секретами; для такого сценария нужна отдельная среда исполнения и проверенная политика доступа.

## Продолжение в собственной учебной копии

Курсы ENG-201/ENG-301 теперь подключены к локальному каталогу. Для сохранённого checkpoint скопируйте starter в отдельную папку, например my-copy, затем выполните:

```bash
node run.mjs ./my-copy
node run.mjs ./my-copy
```

Первый запуск применяет известную правку и проверяет семь случаев, второй возвращает прежний аудит. Оригинальный starter CLI менять отказывается. Файл CANCEL в копии останавливает следующие шаги. Для роли MCP используется `node mcp-readonly.mjs ./my-copy`: один read-only инструмент, протокол 2025-03-26, без сетевого транспорта и команд исполнения. Проверка: `node --test harness.test.mjs mcp.test.mjs`.
