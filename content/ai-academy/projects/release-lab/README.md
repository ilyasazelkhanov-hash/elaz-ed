# Release-лаборатория VC-301

Основа — учебное бронирование VC-201. Добавлены /health и отдельные функции migration/backup. Нужен Node.js 24, зависимостей нет.

```bash
node --test release.test.mjs
node server.mjs
```

Локальный порт — 5180, переменная PORT меняет его. BOOKING_DB задаёт отдельный учебный файл SQLite. Используйте только вымышленные email и пароли. Сервер не предназначен для настоящих клиентов без отдельной подготовки к эксплуатации.

`release.test.mjs` создаёт аккаунт и запись, проверяет /health, делает VACUUM INTO в другой файл, добавляет nullable note, повторяет миграцию и запускает приложение на восстановленной копии. Запись сохраняется, сессия в памяти теряется ожидаемо. Будущая версия схемы не сбрасывается, источник не используется как путь backup.

`migrations.mjs` — библиотека для учебного изменения, не команда для рабочей базы. Перед реальным применением нужны проверенная стратегия снимка, доступы, backup и порядок восстановления. Тест локальной копии не подтверждает production SLA, шифрование диска или многоузловую эксплуатацию.

Внешние уведомления, платежи, rate limiting, HTTPS, корпоративный вход и автоматическая доставка не реализованы. /health подтверждает проверку таблицы, но не заменяет функциональный сценарий регистрации и бронирования.
