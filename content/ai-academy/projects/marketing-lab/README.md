# Marketing lab · MK-101 / MK-201 / MK-301

Все наблюдения созданы автором. Это не результаты реальной кампании, CRM или AI-поиска. Вымышленный бренд «Второй шов» используется для планирования, расчётов и локальных сценариев. Никаких сообщений, рекламных запусков или платежей программа не выполняет.

Node.js 24, без сторонних зависимостей:

```bash
node --test marketing.test.mjs
node generate.mjs
node check-report.mjs
node demo-lifecycle.mjs
node audit-search.mjs
python3 -m http.server 5196 --bind 127.0.0.1
```

Открой `http://127.0.0.1:5196`. Фильтр меняет KPI последнего касания. Два графика показывают полный набор. Поле бюджета меняет сценарий при постоянных коэффициентах; оно не прогнозирует настоящий рынок. 28 календарных записей являются планом, а не опубликованным контентом. reference-page.html содержит видимый FAQ и согласованную учебную JSON-LD-разметку без обещания ранжирования или цитирования.

Контрольные числа: 8 уникальных заказов, 52000 ₸ выручки, 20000 ₸ рекламы, ROAS 2,6. Две платформы дают 11 кредитов и 75000 ₸ приписанной выручки из-за пересечений. Last-touch: search 4 заказа / 25000 ₸, social 4 / 27000 ₸. При валовой марже 40% вклад после рекламы равен 800 ₸ до налогов и постоянных расходов. Стоимость заказа 2500 ₸ не объявляется CAC: уникальные новые клиенты не определены.

CSV-контракт намеренно простой: три поля без кавычек и запятых внутри значения, уникальный order_id, неотрицательные целые суммы и два известных канала. Возвраты и другие единицы требуют отдельного изменения контракта. Дубли, неизвестные кредиты и несогласованные этапы воронки отклоняются. check-report.mjs обнаруживает различие сохранённого расчёта и текущих исходников; он не подтверждает реальность данных.

Синтетический эксперимент: control 20/100, treatment 30/100. Независимая нормальная аппроксимация даёт разницу +10 п.п. и интервал через ноль. Причинный вывод дополнительно требует фактически подходящего дизайна; случайное распределение здесь только допущение учебного примера.

Сценарий бюджета 30000 ₸: 300 кликов, 30 лидов, 18 квалифицированных обращений, ожидаемые 4,5 заказа, 29250 ₸ выручки и −18300 ₸ вклада после рекламы. Дробное значение — математическое ожидание, не реальный заказ. Насыщение и сезонность не моделируются.

lifecycle.mjs требует явный boolean согласия, ограничивает частоту, связывает одобрение с точным текстом и версией согласия. Повтор подготовки того же шага не дублируется. Состояние только в памяти; перезапуск теряет историю. Заявленное имя reviewer не является настоящей учётной записью, а флаг согласия не доказывает его реальное получение. Для рабочего сервиса нужны серверные полномочия, устойчивое хранение и отдельная интеграция доставки.

decision.mjs подготавливает только локальную рекомендацию бюджета. Изменение плана или отчёта делает approval неактуальным. Cap здесь является входом учебной программы, не защищённой политикой. Истечение срока не должно автоматически одобрять внешнее действие.

qualifyLead не является AI-моделью: неполные сведения ведут к уточнению, полного автоматического отказа нет. Тест языковой метки проверяет только одно свойство и не является полным аудитом bias. validateClaims проверяет существование evidence ID, а смысл и правдивость проверяет человек.

search-audit.json содержит шесть авторских макетов ответов, один с упоминанием бренда. audit-search.mjs показывает область наблюдения и оставляет marketVisibility неопределённым. Для своего задания выполни фактические запросы и проверь источники; макеты не заменяют эту практику.

Рисунки включены. Необязательная пересборка: Matplotlib 3.10.8 из requirements-plot.txt в отдельном окружении, затем `python3 plot.py` после `node generate.mjs`.
