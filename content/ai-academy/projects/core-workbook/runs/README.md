# Мои фактические запуски

В исходном архиве нет сохранённых AI-ответов. Пустой журнал означает, что практика ещё не выполнена.

В своей рабочей копии создай файлы с понятными именами, например:

```text
A1-input.txt       — точный разрешённый вход
A1-prompt.txt      — версия запроса
A1-output.txt      — полный фактически полученный ответ
A1-review.md       — найденные нарушения и ручные исправления
```

Это имена будущих файлов, а не перечень выполненных запусков. Не создавай ответ из головы, чтобы заполнить журнал. Сохраняй отказ и ошибку наряду с удачей. Перед передачей проверь, что в материалах нет реальных секретов или лишних персональных данных.

Упаковщик исходного шаблона не включает личные файлы из этой папки. Для сдачи собственной работы собери отдельный разрешённый комплект по правилам курса.
