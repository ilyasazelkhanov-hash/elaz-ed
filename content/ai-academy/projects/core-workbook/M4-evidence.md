## L1 · Путь материала и права

**Маленький шаг:** для одного разрешённого учебного материала нарисуй путь «получил → передал инструменту → сохранил → передал заказчику → опубликовал».

| Материал | Происхождение / версия | Разрешение на обработку | Разрешение на передачу | Разрешение на публикацию | Неизвестное / владелец проверки |
| --- | --- | --- | --- | --- | --- |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

Разрешение на один переход не подтверждает остальные. Проверь также имена файлов, метаданные и вложения; не только видимый абзац. Это метод проверки, а не юридическая сертификация.

## L2 · Проверка отдельного утверждения

**Маленький шаг:** открой [sources-and-facts.md](sources-and-facts.md). Раздели составное обещание на короткие проверяемые тезисы.

1. Для каждого тезиса найди первоисточник, относящийся к конкретному продукту, условиям и дате.
2. Прочитай нужный раздел и запиши точную опору. Набор ссылок без чтения не равен проверке.
3. Исправь неподтверждённое, сохрани исходный вариант и явно оставь неизвестное.

Если источники не открывались, запиши «не проверено». Если текст создан тобой для упражнения, не называй его фактическим ответом модели.

## L3 · Правила и маркировка участия AI

**Маленький шаг:** подготовь короткие правила, по которым участник сможет решить, можно ли продолжать задачу. **Policy** здесь означает рабочие правила применения.

| Вопрос | Моя формулировка | Основание / кто подтверждает |
| --- | --- | --- |
| Какая задача разрешена? | | |
| Какие данные допустимы? | | |
| Какой инструмент и условия выбраны? | | |
| Кто проверяет результат? | | |
| Когда останавливаемся и уточняем? | | |
| Кто разрешает публикацию? | | |

Подготовь три маркировки для разных фактических ситуаций: только план использования AI, AI-черновик после ручной правки, материал без AI. Не приписывай запуск или ревью, которых не было. Реальные правила согласуются с полномочными людьми отдельно.

Репетиция самостоятельно и независимая проверка другим человеком — разные события. Если второго проверяющего не было, прямо обозначь это. Библиотечный пример из тетради не заменяет собственный итоговый проект и не включает ключи квиза.

- [ ] Все заявления о запуске подтверждаются сохранёнными входами и результатами.
- [ ] План, пример и выполненная работа различены.
- [ ] Критерии курса сверены, а ограничения не скрыты.
