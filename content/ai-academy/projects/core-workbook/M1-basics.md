# Модуль 1 · AI-грамотность и запросы

Порядок: CORE-000-M1-L1 → L2 → L3 → L4. Начни здесь. После L4 переходи к [модулю 2](M2-context.md).

## L1 · Основные типы моделей и ограничения

**Маленький шаг:** выбери одну библиотечную задачу и назови наблюдаемый результат. Например, подготовить черновик справки — это текстовая задача; узнать сегодняшнее наличие — задача обращения к актуальному источнику. Не заполняй остальные строки по аналогии без собственного объяснения.

1. Прочитай CURRENT-PUBLIC-01.
2. Запиши четыре собственные задачи, подходящий способ решения и необходимые данные.
3. Для каждой назови проверку и человека, который решает спорный случай.

| Моя задача | Что должно получиться | Метод: правило / поиск / модель / человек | Нужные сведения | Проверка | Неизвестное |
| --- | --- | --- | --- | --- | --- |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

**Проверка:** умеешь объяснить, почему выбранный метод подходит задаче, и назвать его предел. Не приписывай приложению чтение файлов или отправку сообщения, которых не было.

## L2 · От простого запроса к понятному заданию

**Маленький шаг:** скопируй [prompt-template.md](prompt-template.md) и впиши цель, один вопрос, допустимый контекст, формат и три проверки.

1. Сохрани первый вариант запроса до запуска.
2. Если доступ к разрешённому инструменту есть, запусти его и сохрани ответ полностью.
3. Найди конкретное нарушение, измени одно условие и повтори; обе версии оставь в журнале.

| Версия | Что именно изменилось | Почему | Фактическое нарушение в ответе | Где сохранён ответ | Статус |
| --- | --- | --- | --- | --- | --- |
| v1 | | | | | not_run |
| v2 | | | | | not_run |

**Подсказка:** «сделай лучше» замени описанием наблюдаемой ошибки. Хорошо сформулированный запрос всё равно требует проверки ответа.

## L3 · Одна задача в двух инструментах

**Маленький шаг:** до запуска определи одинаковые вход и критерии. Открой [comparison.md](comparison.md).

1. Запиши продукт, показанную модель и включённые возможности. Если версия скрыта, укажи «не раскрыта».
2. Для двух доступных конфигураций повтори одинаковый запрос в новых диалогах; сохрани все попытки.
3. Если доступен только один инструмент, назови ограничение. Не выдумывай второй продукт или наблюдение.

Сравнивай выполнение условий, а не личное ощущение красивого стиля. Один удачный ответ не доказывает общего превосходства.

Квиз проходи самостоятельно в мини-аппке. Эта тетрадь не содержит его вариантов или ключей. Перед переходом объясни, чем ссылка отличается от подтверждения конкретного тезиса.

- [ ] Я сохранил входы и реальные результаты либо честно указал not_run.
- [ ] Неизвестное не заменено выдуманным условием.
