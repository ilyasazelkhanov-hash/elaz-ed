# Creative lab · CR-101 / CR-201 / CR-301

«Второй шов» — вымышленная мастерская. В архиве пять собственных SVG/PNG, два настоящих MP4 (15 и 12 секунд), WAV локальной английской речи flite, русские WebVTT, бриф, storyboard, манифест и работающий цикл QA/approval/export. Это авторская векторная графика и обычный карточный монтаж; они не выдаются за text-to-image или AI video. В consistency-cases.json двадцать параметрических фикстур, не ответы модели.

Просмотр без подписок:

```bash
python3 -m http.server 5194 --bind 127.0.0.1
```

Открой `http://127.0.0.1:5194`. Для самостоятельной AI-практики используй подходящий инструмент по его текущим условиям, сохраняй фактические запуски и не выдавай готовые примеры за свой итоговый проект. Если сервис недоступен, отметь невыполненную часть; подготовленный запрос не равен генерации.

Node.js 24 и FFmpeg/ffprobe нужны для проверок:

```bash
node --test qa.test.mjs
node workflow.mjs check
node workflow.mjs approve --reviewer=teacher
node workflow.mjs release
```

Команда approve — локальное учебное решение с заявленным именем проверяющего, без настоящей аутентификации. Экспорт создаёт только папку release; публикаций, писем, платежей и обращений к AI API нет. После изменения PNG, исходного SVG, VTT, WAV или манифеста прежний digest больше не принимается. Код запрещает выход за папку ассетов и символические ссылки. Это не OS sandbox; человек с правом редактировать программу может изменить правила.

QA проверяет размеры PNG, видео/аудиопотоки, длительность, наличие подписи и заявленных записей о правах. Он не распознаёт анатомию, не подтверждает реальное владение, не оценивает коммерческую эффективность и не создаёт C2PA-подпись. Checksum связывает байты, но не доказывает правдивость содержания. Смысл и основания проверяются отдельно человеком.

Бюджет вымышленный: 12 часов × 4000 ₸, два раунда по 1,5 часа и 2000 ₸ инструментов = 62000 ₸ затрат. При цене 90000 ₸ маржа около 31,1%. Налоги и рекламные расходы не включены; это не рекомендация цены.

Пересборка примеров необязательна. Нужны Node.js 24, Python не требуется, Playwright 1.62.1, системный Chromium и FFmpeg с фильтром flite. Установи зависимости по включённому lockfile; скачивать браузер не требуется, если есть Chromium:

```bash
npm ci --ignore-scripts
node make-assets.mjs
node render.mjs
node make-manifest.mjs
```

По умолчанию браузер `/usr/bin/chromium`; другой путь передай через `CHROMIUM_BIN`. `node render.mjs --media-only` пересобирает только звук, VTT и видео из готовых PNG. Встроенный голос английский, не имитирует конкретного человека. Для русскоязычного выпуска подготовь свою подходящую озвучку и проверь произношение. Текстовая расшифровка находится в странице просмотра. Условия инструментов, голоса и исходников перед настоящим использованием проверяются отдельно.
