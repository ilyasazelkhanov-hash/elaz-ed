# Лаборатория аналитики · DT-101 / DT-201 / DT-301

Вымышленная мастерская: очистка заказов, SQL, KPI, исследовательские ограничения, A/B-анализ и прогноз. Все наблюдения синтетические. Эта лаборатория не использует настоящие персональные данные, внешнюю базу, AI API или платную подписку.

Нужен Python 3.12+. Распакуйте архив и откройте терминал в этой папке:

```bash
python3 -m unittest test_analysis.py -v
python3 check_report.py
python3 evaluate_sql.py
python3 query.py 'select count(*) as n, sum(total_kzt) as revenue from orders'
python3 -m http.server 5193 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:5193`. Фильтр меняет KPI и таблицу; сохранённые рисунки показывают полный набор. Готовые рисунки и `report.json` уже включены — дополнительные пакеты для просмотра не нужны.

Основные контрольные числа: 11 исходных строк → 8 принятых и 3 исключённых; выручка 13500 ₸; средний чек 1687,50 ₸; задержаны 4/8 = 50%. JOIN заказов со строками услуг ошибочно раздувает сумму заголовков до 20000 ₸. Сумма строк услуг и сумма уникальных заказов — 13500 ₸. Сначала проверьте расчёт вручную и только затем объясняйте результат AI.

Пересборка отчёта из текущих исходников:

```bash
python3 analysis.py > report.json
python3 check_report.py
```

Пересборка рисунков необязательна. Установите Matplotlib в отдельное окружение:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-plot.txt
.venv/bin/python plot.py
```

В Windows используйте `.venv\Scripts\python.exe`. `plot.py` также обновляет отчёт. Fingerprint связывает отчёт с анализом, CSV, экспериментом и словарём; изменение этих файлов делает прежний отчёт устаревшим. Он не удостоверяет происхождение наблюдений и не проверяет содержание PNG.

В `source-ledger.json` десять проверенных ссылок на методику и инструменты; девять относятся к одному издателю CPython. Они не являются десятью независимыми источниками бизнес-фактов. Источник учебных наблюдений — авторский синтетический набор.

`analysis.py` использует стандартную библиотеку. SQL исполняется в отдельной SQLite в памяти: разрешены только чтение двух публичных таблиц и ограниченный набор агрегатов; количество строк и шагов ограничено. Приватная учебная таблица, запись и ATTACH отклоняются. Это граница инструмента внутри доверенного процесса, а не защита от человека, который может редактировать Python. Разрешённый запрос всё ещё может считать неправильную метрику: `evaluate_sql.py` отдельно показывает права и смысл результата.

A/B-пример использует независимую нормальную аппроксимацию и явно заданные допущения. Интервал разницы пересекает ноль; результат не доказывает отсутствие эффекта. Расчёт размера групп приблизителен. Rolling backtest передаёт прогнозу только доступную историю, но короткий синтетический ряд не даёт гарантии для настоящего бизнеса.

Для итоговой работы измените вопрос, сохраните контракт и доказательства проверки, затем объясните своё решение и ограничения. Простое копирование готового отчёта не закрывает критерии защиты курса.
