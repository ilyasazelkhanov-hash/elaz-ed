# Business lab · BI-101 / BI-201 / BI-301

Вымышленная мастерская и синтетические заметки. Здесь нет настоящих участников, отправки писем или внешнего AI API. Текущий готовый блок — рабочие сценарии: разрешённый контекст, протокол, повестка, evidence и черновик follow-up. Новые расчёты и сценарии управления добавляются по мере готовности модулей.

Node.js 24, без зависимостей:

```bash
node --test business.test.mjs
node generate.mjs
```

packet.json и follow-up.md уже включены. work.mjs — детерминированный baseline по размеченным заметкам, не ответ живой LLM. Неизвестные владельцы и сроки остаются неизвестными. Внутренние записи исключаются до формирования контекста. Валидатор проверяет цитату и обязательство, но смысл интерпретации проверяет человек.

backlog.json содержит пять сценариев с входом, выходом и критерием. Для собственной AI-практики выбирай разрешённые данные, сохраняй фактический запуск и проверку; подготовленный запрос не выдаётся за выполненную работу. Готовые примеры — опора для упражнения, а не собственный итоговый проект.

## Время, качество и стоимость

`pilot.csv` — восемь синтетических пар: 250 минут вручную, 74 минуты на черновики, 187 минут вместе с ревью и исправлениями. Качество AI — 6/8; весь выигрыш 63 минуты не считается выигрышем при одинаковом качестве. Для шести пар, прошедших обе проверки, разница 41 минута; отбор успешных случаев ограничивает вывод.

`economics.mjs` и `report.json` показывают эти границы и блокируют масштабирование при пороге качества 0,9. В `scenario.json` вымышленные KZT-допущения: 160 задач/месяц, 6 минут/задачу, 4000 ₸/час, внедрение 120000 ₸, инструменты 20000 ₸/месяц, поддержка 30000 ₸/месяц и 25 ₸/задачу. За три месяца стоимость 282000 ₸, оценка ёмкости 192000 ₸, разница −90000 ₸. Это сценарная оценка времени, не доказанная денежная экономия.

Опциональные графики: Python 3 + Matplotlib 3.10.8, `python3 figures.py`. Основные расчёты и тесты не требуют Python или сторонних пакетов.
