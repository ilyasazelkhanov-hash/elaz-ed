# Учебное бронирование · VC-201

Требуется Node.js 24. Внешних зависимостей нет. В распакованной папке:

```bash
node --test server.test.mjs
node server.mjs
```

Сервер слушает только локальный интерфейс, порт 5180. Открой этот порт в браузере своей машины. Создай аккаунт с вымышленным email и учебным паролем длиной 12–128 символов. Записывайся на январь 2030 года, ровно 09:00, 10:00 или 11:00. Пример работает с локальной SQLite, файл booking.sqlite создаётся в текущей папке. Его не нужно коммитить или отправлять вместе с работой. PORT меняет порт, BOOKING_DB — путь к файлу базы.

Данные аккаунтов и записей сохраняются после перезапуска; сессии хранятся в памяти один час и после перезапуска исчезают. Уведомления представлены только строками outbox со статусом draft. Внешняя доставка отсутствует.

Это учебный стенд для вымышленных данных. Перед рабочим использованием нужны HTTPS, ограничение частоты запросов, управление сессиями, миграции, резервное копирование и отдельная проверка эксплуатации. API не содержит административной роли, отмены записей или настоящей оплаты.
