# Лаборатория AG-101 / AG-201 / AG-301

Нужен Node.js 24, внешних зависимостей нет. В распакованной папке:

```bash
node --test retrieval.test.mjs tasks.test.mjs evaluation.test.mjs server.test.mjs
node evaluate.mjs
node server.mjs
```

Откройте локальный порт 5192. PORT меняет порт. Браузерный режим использует лексический BM25-подобный поиск, простую нормализацию русских окончаний и точное извлечение текста. Он не вызывает настоящую модель и не содержит векторной базы. Документы вымышлены, архив и закрытые записи исключаются до выдачи студенту.

Вставленный JSON проверяется по структуре и точному фрагменту разрешённого источника. Это не доказывает истинность всех утверждений ответа. `grader.mjs` и тест калибровки намеренно показывают ложное принятие: цена 1500 с неподтверждённым обещанием бесплатного ремонта проходит простые сигналы. Решение о внешнем действии не должно зависеть от одного такого сигнала.

`eval-cases.json` содержит 30 фиксированных вопросов с ожидаемыми источниками и handoff. Он не является общей сертификацией моделей. При разработке нормализация исправлена на прежних вопросах об адресе; случай неизвестного срока заказа требует сотрудника.

## Состояние и checkpoint

```bash
node checkpoint.mjs prepare ./teaching.sqlite
node checkpoint.mjs execute ./teaching.sqlite
node checkpoint.mjs execute ./teaching.sqlite
```

Подтверждение reviewer в CLI имитируется кодом, настоящего входа преподавателя нет. Первый execute создаёт один локальный ticket, повтор возвращает прежний результат. Отдельные тесты проверяют отмену, чужого владельца, self-review, смену payload после approval и повторное открытие файла. Файл содержит только учебное состояние; не коммитьте его. Внешние сообщения и деньги не отправляются.

## Необязательный настоящий API

`model-adapter.mjs` содержит ограниченный клиент совместимого с Chat Completions API. Он проверен с подменённым поставщиком, а не живой моделью. Для отдельного эксперимента задайте через защищённые настройки AI_API_URL (полный HTTPS endpoint), AI_API_TOKEN и AI_MODEL. Не записывайте значения ключей в исходники, архивы или чат. Проверьте доступность нужного домена и поддержку JSON-ответа у выбранного поставщика. При прокси используйте поддерживаемые настройки Node среды.

`node live.mjs 'Сколько стоит диагностика?'` отправляет только отобранные публичные учебные источники. Отсутствие нужных переменных выводится по именам без значений. Локальные тесты не подтверждают доступность этого внешнего вызова, стоимость или качество реальной модели. Схема ответа не разрешает инструменты и не заменяет проверку фактов.
