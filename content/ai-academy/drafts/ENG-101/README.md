# ENG-101 · разработка учебного пакета

Первое занятие написано в `01-environment.md`. Исполняемый пример и восемь тестов находятся в `starter/`. Проверены успешный запуск и обнаружение намеренно неверной скидки в отдельной временной копии.

Это авторский черновик первого занятия, а не опубликованный курс. Статусы каталога не менялись. Следующий этап: занятия по настройке Git/терминала, фиксации исходного состояния и диагностике окружения; затем сборка полного пакета из 16 занятий через существующий валидатор. Для включения в приложение потребуется подключить полный пакет к `scripts/academy-content.mjs` и проверить сохранность прогресса.
