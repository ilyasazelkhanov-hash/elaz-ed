# Пять самостоятельных курсов

Пользователь попросил отдельные курсы: основы и инструменты, текст и исследования, медиа, вайбкодинг, автоматизация. В каждом нужен основной маршрут для новичка, подробные действия в интерфейсе, иллюстрации/анимации и дополнительные возможности для опытного пользователя.

Решение: 5 курсов по 6 уроков, всего 30. Переносим 14 прежних уроков по прежним ID, добавляем 16 новых. Курс ID исходного импорта становится основами; четыре новых курса защищены маркером импорта. Прогресс, XP и доступ сохраняются. Обзоры инструментов и существующие новости не меняются. Уроки не дублируются в Telegram; ручной анонс курса также запрещён на сервере и скрыт в редакторе.

Пользователь выбрал **250 ⭐ за каждый курс отдельно**. Первый урок каждого курса ознакомительный; остальные требуют отдельного доступа. Общего платёжного набора нет. При первом переносе сохранены прежние административные доступы; наличие прохождения прежнего урока сохраняет доступ к соответствующему новому курсу. Повторный импорт не распространяет новые индивидуальные покупки/выдачи на другие курсы.

Схема урока: маршрут по уровню → входные материалы → объяснение → схема/анимация → шаги с целью и ожидаемым результатом → пример запроса → ошибки и ручная альтернатива → самостоятельный повтор → критерии → продвинутое расширение. Скриншоты только из текущей официальной справки с пояснением происхождения; учебные схемы не выдаются за интерфейс. Терминальные операции допустимы только в явно дополнительной практике, не как обязательный путь новичка.

Фокус расширений: собственный Skill и разбор плагина; чтение источников через коннектор/Agent Reach; Descript MCP; OpenCode V2 и Context7; процедура + коннектор + управляемое расписание. Платные функции необязательны, расход модели и сервиса поясняется отдельно.

Исследование методики зафиксировано в paths-research.json: публичные программы OpenAI Academy/Boot.dev и подробный tutorial n8n. Заимствован формат обучения, а не тексты закрытых уроков.

Публикация: GitHub/Vercel со статическими файлами, затем функция API с запретом анонса курса, затем конкретный paths.sql. Не применять старые training.sql/revision.sql после разделения. Проверить 5×6, сохранение ID/прогресса/доступа, отсутствие новых записей ленты и очереди Telegram. Тесты включают повтор импорта, повреждённое сопоставление и откат, API запрета и мобильный просмотр каждого курса.
