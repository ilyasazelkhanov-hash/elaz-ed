# ИИ на практике · OG CRE8R²

## Текущая учебная программа

### Пять отдельных курсов (актуальная версия)

`tool-recommendations.mjs` задаёт конкретный основной сервис, применение, первый шаг и альтернативу/следующий этап для всех 30 уроков. Вводная таблица содержит прямые ссылки на рекомендуемые продукты вместо одних категорий «чат»/«генератор». Проверки официальных страниц — в `tool-recommendations-sources.json`; точные квоты и неподтверждённые рейтинги не обещаются. Генератор заменяет раздел выбора инструментов при сборке `paths.json`/`paths.sql`, не изменяя исторический входной снимок `training.json`.

`tool-alternatives.mjs` расширяет программу до 35 разных инструментов/сервисов (включая вспомогательные Git и MCP). В основном маршруте остаётся понятный старт, а после основной практики — дополнительные варианты по теме: когда попробовать, как начать, что проверить. Вводный выбор явно включает ChatGPT/GPT, Claude, DeepSeek, Gemini, Qwen Studio и актуальный Mistral Vibe. В медиа добавлены Midjourney, Ideogram, Recraft, Kling, Pika, Luma, HeyGen, Stable Audio и Udio с ограничением скачивания; в коде Cursor/Copilot, в автоматизации Make/Zapier. Источники и ограничения — в `tool-alternatives-sources.json`.

Основы и инструменты, текст и исследования, медиа, вайбкодинг, автоматизация — пять самостоятельных курсов по шесть уроков. Источник `build-paths.mjs` + `path-lessons.mjs`, результат `paths.json` и `paths.sql`. Новых уроков 16; все 14 прежних переносятся с прежними ID. Финал вайбкодинга заменён самостоятельной приёмкой HTML-проекта, а не заданием на медиа из другого курса. В каждом уроке основной маршрут и отдельное усложнение; вводный урок каждого курса содержит расширения, MCP/Skills/коннекторы с условиями доступа.

Сборка: `node content/ai-practice-2026-10-25/build-paths.mjs`. Пять SVG-схем, пять дополнительных официальных скриншотов и ZIP учебного Skill входят в статический релиз. ZIP содержит `focus-brief/SKILL.md`; исходник читается до загрузки. Методика и проверки интерфейсов зафиксированы в `paths-research.json` и `paths-design.md`. Скриншоты не выдаются за собственный вход в чужой аккаунт, анимации — учебные схемы.

Развёртывание: статические файлы через Vercel → функция `api` с запретом `admin_announce` для курсов → **только `paths.sql`**. После разделения не применять исторические `training.sql`, `revision.sql` и первоначальные импорты: старые проверки размера курса останавливают такой запуск. `training.json` остаётся входным снимком старой программы для генератора, а не актуальной программой публикации.

`paths.sql` защищён транзакцией, advisory lock и маркером. Курс исходного импорта становится основами, четыре новых получают сохранённые сопоставления. ID уроков, прогресс, XP и выданный доступ сохраняются; новости и журнал рассылки не меняются. Полностью читаемые курсы без цены открываются в интерфейсе без бессмысленной заявки, смешанные курсы остаются закрытыми. Автопубликация берёт только новости; ручной серверный анонс также отклоняет любой урок курса, включая бесплатный.

По явному выбору пользователя каждый курс стоит **250 ⭐ отдельно**; первый урок ознакомительный. Единого платёжного набора нет. При первом разделении прежние отметки прохождения дают доступ к соответствующему курсу; последующие индивидуальные выдачи не распространяются повторным импортом. Миграция не меняет платёжные RPC и не вызывает рассылок.

Проверки: `node --test tests/learning-paths.test.mjs`, `npm run test:api`, `npm run test:news`, `npm run build`; браузерные проверки пяти курсов и 30 уроков на 320/390 px, увеличение нового скриншота и ZIP. Старые разделы ниже описывают историю до разделения.

### Адаптация внешних ориентиров 26 октября 2026

`training-labs.mjs` добавляет 10 дополнительных практик в существующие 14 уроков пяти модулей: сравнение инструментов, повторяемая процедура, Gemini Notebook, отчёт по CSV, Gamma 5, нарезка Descript, файлы Claude Desktop, карта процесса, приёмка OpenCode и портфолио на 30 дней. Базовые 540 минут не включают необязательные дополнительные задания. Восемь учебных шаблонов и официальная иллюстрация Descript находятся в `public/learning/ai-practice/`.

`reference-audit.json` фиксирует все 11 ссылок пользователя и первичные проверки. Это выборочная авторская адаптация публичных тем, не зеркало каталогов. У Stepik прочитаны только открытые метаданные и разделы; платные уроки не извлекались. YouTube дал названия и описание, но видео и транскрипты не изучены; утверждения о новых моделях по названиям видео не переносились. Обновлённые маршруты Gemini Notebook, Gamma 5 и Claude проверены по официальной справке. Рекламные рейтинги и обещания экономии исключены.

Сборка: `node --experimental-strip-types content/ai-practice-2026-10-25/build-training.mjs`, затем `node content/ai-practice-2026-10-25/build-reference-expansion.mjs`. После публикации файлов Vercel применить сначала `training.sql`, затем `reference-posts.sql`. Второй файл добавляет 8 материалов только в ленту; повторный импорт не создаёт дубли. Существующий worker автоматически публикует их в Telegram по порядку. Проверки: `node --test tests/reference-expansion.test.mjs tests/training-course.test.mjs`.

В 10 подходящих уроках добавлены управляемые учебные анимации (`src/lib/lesson-animations.ts`, `src/LessonAnimation.tsx`). Они показывают проверку источников и запросов, слои изображения, таймлайн видео, исправление расшифровки, баланс музыки/голоса, расписание, ветки и дубли событий, состояния формы и проверку правки кода. Это самостоятельные учебные схемы, не имитации интерфейса сервиса. Пауза, шаг назад/вперёд и повтор работают без внешних библиотек или видеофайлов. За экраном и в скрытой вкладке таймер останавливается; при reduced motion старт ручной. Три прежних неуправляемых GIF больше не вставляются в уроки, файлы сохранены как исторические материалы.

Сборщик вставляет только известные `lesson-animation` ID. Неизвестный блок остаётся обычным кодовым блоком. Проверки: `npm run test:lesson-animations` и `npm run test:training`; браузерная QA проверяет все 10 сцен, 320 px, ручные шаги, паузу, reduced motion и уход за экран.

Уточнение интерфейсов 26 октября: во всех 14 уроках блок первого запуска теперь объясняет «куда нажать / что ввести → зачем → что должно появиться» (`training-walkthroughs.mjs`). Добавлены 8 проверенных иллюстраций интерфейсов из официальных материалов, исходные URL и страницы сохранены в `walkthrough-images.json`; загрузчик — `fetch-walkthrough-images.mjs`. Иллюстрации не выдаются за снимки пользовательского аккаунта или подтверждение доступа к платным функциям.

На телефоне Markdown-сравнения отображаются карточками, на широком экране — таблицами. Изображения открываются в увеличиваемом просмотре с горизонтальной прокруткой и закрытием через кнопку или Escape. Браузерная проверка на 320/390/900 px подтвердила отсутствие переноса названий по буквам, сохранность содержимого карточек, настольной таблицы и работу увеличения.

По уточнению пользователя обзоры инструментов остаются только в новостях. Курс ID 3 переработан в обучение «ИИ с нуля: текст, медиа, автоматизация и вайбкодинг»: 5 модулей, 14 уроков, около 9 часов практики. Каждый урок содержит объяснение, пример, бесплатный и платный маршрут, первый запуск, самостоятельное задание, критерии и вопрос с разбором. Возможности и условия проверены по связанным официальным страницам на 26 октября 2026. Наличие бесплатного приложения не приравнивается к бесплатным моделям/API, скачиванию или коммерческим правам.

## История: исправление обзоров 26 октября 2026

`node build.mjs` и затем `node revise.mjs` создают `revision.sql`: обновление уже импортированных текстов по сохранённым ID, очистка рекламных упоминаний и два новых микропоста с двумя отдельными блоками курса — OpenBot (openbot.run, не OpenClaw) и Agent Reach. Итого 58 микропостов и 10 блоков. Для существующей базы применять `revision.sql`, а не повторять первоначальный INSERT-only импорт. Скрипт сохраняет ID, прогресс и журнал Telegram; новые записи защищены отдельным маркером от дублей. Перед применением нужен исходный импорт обоих пакетов.

`supplement.mjs` содержит практические уроки и прямые ссылки на продукты; `editorial.mjs` — самостоятельные редакционные версии семи кейсов без ссылок на блогеров. Внутренний исходник и история происхождения материалов сохранены. Исходные карточки 01–56 покрыты полностью; это не утверждение, что каждый справочный пункт большого архивного приложения превращён в отдельный урок. Неподтверждённые слухи не публикуются как факты.

Проверки: `npm run test:content-revision`, `npm run test:news`, `npm run test:api`, `npm run build`. Тест ревизии проверяет повторный запуск, смещённые ID старого импорта, сохранение прогресса и точное число новых блоков. Новые анонсы отправляет существующий автопостинг; режим `refresh_news` редактирует прежние сообщения по журналу публикаций, не создавая новые.

## Файлы

- `source.md` — предоставленный материал, включая редакционные оговорки и исходный архив; в публикацию попали только карточки 01–56.
- `build.mjs` — сборка текстов, программы, payload, SQL и локальной страницы просмотра.
- `payload.json` — 56 постов и 8 блоков курса.
- `import.sql` — добавляющий транзакционный импорт с advisory lock и маркером `content_import:ai-practice-2026-10-25-v1`; повторный запуск ничего не меняет.
- `images.json` — источники интернет-обложек, привязки к карточкам и результаты загрузки. 32 привязки, некоторые используют одно изображение соответствующего сервиса. Для разборов сообщества отдельно указана тематическая иллюстрация Claude. Обложки загружаются с сайтов издателей; их адреса могут измениться.
- `images.mjs`, `finalize-images.mjs` — подбор и HTTP-проверка изображений; требуют сети. Запуск `images.mjs` заменяет manifest, после него требуется `finalize-images.mjs`.
- `review.html` — локальный просмотр всех материалов и программы.
- `verify.mjs`, `verification.json` — проверка на локальной PostgreSQL/PGlite: повторный импорт, прежние тексты и прогресс, полнота дублирования в курс, обложки.
