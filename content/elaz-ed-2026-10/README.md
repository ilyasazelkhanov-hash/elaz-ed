# Материалы Elaz Ed

Пакет содержит 84 материала: 42 карточки инструментов, 15 гайдов, 7 промптов и курс из 20 текстовых уроков в шести модулях. В каждом уроке курса есть практика и квиз. Тексты переработаны, темы и порядок сохранены. Тарифы, статистику и применимость правовых требований нужно проверять на дату использования.

## Файлы

- `tools.mjs`, `guides.mjs`, `prompts.mjs`, `course.mjs` — редактируемые материалы.
- `build.mjs` — проверка структуры и генерация JSON и SQL.
- `payload.json` — полный каталог.
- `import.sql` — идемпотентный импорт без изменения существующего прогресса.
- `update-existing.sql` — обновление текстов и ссылок уже перенесённых материалов.
- `schema-new-project.sql` — миграции только для пустого проекта.
- `review.mjs` — локальная страница для переноса через SQL-редактор.
- `assets/` и `assets-manifest.json` — 50 файлов с размерами, SHA-256 и адресами собственного хранилища.
- `download-assets.mjs` — восстановление файлов из собственного хранилища с проверкой хэшей.
- `verify-live.mjs` и `verification.json` — проверка API и файлов.
- `live-miniapp.jpg` — снимок работающей миниапки.
