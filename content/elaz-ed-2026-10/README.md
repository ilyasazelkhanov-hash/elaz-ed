# Материалы OG CRE8R²

Пакет содержит 84 материала: 42 карточки инструментов, 15 гайдов, 7 промптов и курс из 20 текстовых уроков в шести модулях. В каждом уроке курса есть практика и квиз. Тексты переработаны, темы и порядок сохранены. Тарифы, статистику и применимость правовых требований нужно проверять на дату использования.

## Файлы

- `tools.mjs`, `guides.mjs`, `prompts.mjs`, `course.mjs` — редактируемые материалы.
- `build.mjs` — проверка структуры и генерация JSON и SQL.
- `payload.json` — полный каталог.
- `import.sql` — идемпотентный импорт без изменения существующего прогресса.
- `update-existing.sql` — обновление текстов и ссылок уже перенесённых материалов.
- `course-price.sql` — цена и описание курса для работающего проекта. Запускается один раз; дальше цену меняет автор в админке.
- `schema-new-project.sql` — миграции только для пустого проекта.
- `review.mjs` — собирает `review.html`: страницу с готовым SQL и кодом функции для переноса через панель Supabase. Шаги обновления работающего проекта идут в ней первыми.
- `assets/` и `assets-manifest.json` — 50 файлов с размерами, SHA-256 и адресами собственного хранилища.
- `download-assets.mjs` — восстановление файлов из собственного хранилища с проверкой хэшей.
- `verify-live.mjs` и `verification.json` — проверка API и файлов.
- `live-miniapp.jpg` — снимок работающей миниапки.

- Заявка не дублирует сообщения админам; доступ по `@username` с подчёркиванием выдаётся точно; адреса вроде `/constructor` больше не отвечают.
- Вебхук ставится на адрес своего проекта, настройка `api_url` удаляется.

Порядок (в `review.html` те же три шага идут первыми):

1. SQL-редактор: `supabase/migrations/007_refunds_webhook_url.sql`. Добавляет `payments.refunded_at` и удаляет `api_url`. Повторный запуск безопасен.
2. Edge Functions → `api`: заменить код на `supabase/functions/api/index.ts` целиком. Проверку JWT оставить выключенной, секрет `BOT_TOKEN` не трогать.
3. SQL-редактор: `course-price.sql`. Ставит цену 250 и новое описание курсу из маркера импорта.
4. Проверка: `node verify-live.mjs` — помимо прежнего, ждёт `404` на `/functions/v1/api/constructor` (признак новой функции). Затем в Telegram: у курса видна кнопка «Открыть за ⭐ 250», счёт открывается, после оплаты курс открыт, в админке покупка видна в «Покупках».

Шаг 1 обязателен до шага 2: новая функция читает `refunded_at`. Шаг 3 лучше после шага 2: тогда продажи сразу идут через новый код.

Перед переносом можно прогнать проверку функции локально: `npm run test:api` (Node 24, сеть не нужна).
