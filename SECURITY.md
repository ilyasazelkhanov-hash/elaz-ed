# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue и не описывайте проблему в pull request.

1. Откройте вкладку **Security** этого репозитория и нажмите **Report a vulnerability**. Сообщение увидит только владелец.
2. Если такой кнопки нет, напишите владельцу репозитория лично через его профиль на GitHub и не раскрывайте детали публично, пока проблема не закрыта.

В сообщении укажите, что именно можно сделать, шаги воспроизведения на тестовых данных и затронутую часть: интерфейс, Edge API, база, бот или оплата.

Не прикладывайте настоящие токены, данные учеников и тексты платных уроков. Не проверяйте находку на чужих аккаунтах и не выполняйте реальные платежи.

## Что считается уязвимостью

- Вход или действие без верной подписи Telegram `initData`.
- Чтение платного урока без доступа к курсу.
- Админская операция без прав администратора.
- Выдача доступа, XP или награды в обход сервера.
- Подделка оплаты, возврата или кода награды.
- Утечка секретов, персональных данных или закрытых материалов через репозиторий, сборку или ответы API.

## Что уже учтено

Модель защиты и известные ограничения, которые не считаются дырой, описаны в разделе «Безопасность» в [README](README.md). Перед сообщением сверьтесь с ним.

## Поддерживаемая версия

Исправления выпускаются только для текущего `main` и действующего production. Выкладка фронтенда и выпуск Edge API идут раздельно: порядок описан в [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Не про безопасность

Вопросы по оплате и доступу к курсу принимает бот по команде `/paysupport`.
