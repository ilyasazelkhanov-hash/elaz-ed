# AU-101 · автоматизация без кода

16 занятий объясняют процесс заявки, фильтры, повторы, проверку структуры ответа модели, ручной разбор, измерение эффекта и восстановление. Два занятия содержат квизы, остальные — практику с критериями; финал — защита процесса.

В `content/ai-academy/projects/AU-101/` находится визуальная лаборатория без внешних сервисов. Настройки меняются флажками и списками. Таблица и черновики живут в памяти страницы, реальная модель не вызывается, уведомления не отправляются. Архив для студента: `public/learning/academy/au-101-lab.zip`.

Схема `n8n-workflow.json` импортирована и исполнена в n8n 2.44.7 на Node 24. Проверены корректный вход и ветка отказа для пустого email. Для повторной проверки используется `verify-n8n.mjs` с отдельной временной базой, без изменения пользовательского n8n. В этой среде инструмент установлен отдельно в `/workspace/.learning-tools/n8n`.

Проверки: семь тестов логики, браузерные сценарии записи/повтора/отказа/сбоя, все 16 страниц занятий и загрузка ZIP. `npm run test:academy` включает тесты лаборатории. CLI n8n проверяется отдельно, поскольку это дополнительный инструмент, не зависимость приложения.

Индекс наполненных курсов теперь хранится в `content/ai-academy/authored/index.json`. Сборка и тесты читают один список, проверяют идентичность и полноту пакетов. SQL-проверка последовательно добавляет каждый новый курс к существующим, а не пересоздаёт старые материалы.

Серверный экспорт: `npm run academy:content -- --actor=TELEGRAM_ID --course=AU-101`. Укажите реальный ID администратора, проверьте SQL и backup перед применением. Команда экспорта не подключается к рабочей базе.
