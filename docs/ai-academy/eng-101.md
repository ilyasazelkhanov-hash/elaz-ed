# ENG-101: разработка с AI

Курс наполнен 16 авторскими занятиями в четырёх модулях. Один учебный проект проходит через среду, Git, постановку задачи агенту, ограничение контекста, тестирование, подготовку PR и защиту. В каждом занятии есть объяснение, разобранный случай, практический результат, критерии и помощь при затруднении. Все задания оцениваются по практике; итог — отдельная защита.

Исходный пакет: `content/ai-academy/authored/ENG-101.json`. Минимальный объём основного материала — более 250 слов на занятие. Иллюстрация направления и общий блок подсказок подключаются существующим интерфейсом. Starter доступен по ссылке из первого занятия; архив содержит два файла без зависимостей. Эталон расширения хранится отдельно от студенческого архива.

Практическая задача: цена ремонта, скидка только на работу при достижении порога, затем отдельный фиксированный сбор. Проверены восемь исходных и пять дополнительных случаев, включая границу порога, неверные данные и переполнение. Изменение коэффициента скидки в временной копии обнаруживается тестами. Оплата и реальные клиентские данные не используются.

Официальные источники Node.js Test runner и GitHub Git guides проверены 26 октября 2026. Ссылки привязаны ко всем занятиям. Специфика конкретного coding-клиента не выдаётся за универсальное поведение: способ чтения инструкций проверяют для выбранного инструмента.

## Подключение

`npm run academy:content` включает три наполненных курса, всего 48 занятий. Ещё 400 занятий остаются планами. В локальном dev учебные тексты доступны через существующие правила зачисления; ENG-101 требует завершённого Core или подтверждённого входного уровня. Production demo по умолчанию не включает полные учебные тексты.

Для сервера сначала должны существовать curriculum и необходимые миграции. Экспорт только нового курса:

```bash
npm run academy:content -- --actor=TELEGRAM_ID --course=ENG-101
```

Замените TELEGRAM_ID реальным ID администратора. Экспорт создаёт SQL, но не подключается к базе. Ограничение `--course` позволяет добавить ENG-101 к уже опубликованным Core/VC-101; повтор экспорта той же редакции не меняет данные, а конфликт с отредактированными материалами останавливает транзакцию. SQL применяют после проверки и резервного копирования. Рабочая база в этой задаче не изменялась.
