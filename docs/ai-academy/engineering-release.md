# ENG-201, ENG-301 и VC-301

Три пакета добавляют 48 занятий по контексту, инструментам, ролям, ограничениям runtime, проверкам и выпуску продукта. Для каждого есть практика, критерии, квиз и итоговая защита.

`engineering-lab` содержит детерминированный конвейер из чтения, заранее проверенной правки и запуска семи случаев. Проверяются роли, бюджет шагов, timeout, путь, symlink, сохранность неизвестных ручных изменений, failed, cancel и checkpoint. Реальная coding-модель не вызывается. Контроль плана не объявляется ОС-изоляцией, а один JSON checkpoint — безопасной конкурентной очередью.

Read-only MCP поддерживает initialize/initialized, tools/list и tools/call по stdio с протоколом 2025-03-26. Проверены handshake, успешное чтение и отказ выхода за допустимый путь. Это не сетевой сервер, не произвольный shell и не подтверждение совместимости любого клиента без отдельного подключения.

`release-lab` — учебное бронирование на основе VC-201 с /health и функциями SQLite migration/backup. Проверены добавление nullable note без потери записи, повтор миграции, отказ неизвестной будущей версии, отдельный VACUUM INTO и запуск приложения на восстановленной копии. Сессия в памяти ожидаемо требует нового входа. Рабочие платежи, внешние уведомления, HTTPS, rate limiting и кластер отсутствуют.

Архивы: `public/learning/academy/engineering-lab.zip` и `release-lab.zip`. Оба запускаются на Node 24 без зависимостей. Проверка: 128 тестов Академии, сборка, браузерный путь регистрации/бронирования, все 48 страниц новых занятий, загрузка архивов и CLI продолжения. Архивы проверены на целостность и отсутствие SQLite/файлов значений окружения.

[Актуальный прогресс](content-status.md) формируется из каталога. Серверный экспорт выполняется отдельно для ENG-201, ENG-301 или VC-301 через `npm run academy:content -- --actor=TELEGRAM_ID --course=COURSE_CODE`. Нужны реальный администратор, проверка SQL и backup перед применением; рабочая Supabase в этой задаче не изменялась.
