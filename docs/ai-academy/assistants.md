# AG-101, AG-201 и AG-301

Три учебных пакета содержат 48 авторских занятий: ограниченный помощник, поиск и RAG, источники и версии, проверка ответов, схемы инструментов, подтверждения, durable-состояние, отмены, калибровка grader и эксплуатационный план. Каждый пакет имеет практику с критериями, квиз и итоговую защиту.

Общий проект находится в `content/ai-academy/projects/assistant-lab/`. Архив: `public/learning/academy/assistant-lab.zip`. Требуется Node 24, внешние зависимости отсутствуют. Для модулей добавлены две собственные учебные схемы — путь ответа и состояния задачи. Они восстанавливаются командой `node scripts/academy-agent-diagrams.mjs`.

Браузерный baseline выполняет лексический BM25-подобный поиск и извлечение текста из синтетического справочника. Архивные и недоступные источники исключаются до построения контекста. Это не настоящий вызов LLM и не установленная векторная база. Адаптер совместимого API проверен с подменённым поставщиком; живое подключение требует отдельных защищённых настроек и функционального запроса.

Фиксированный набор содержит 30 случаев. До исправления нормализации верный первый источник находился в 27 случаях; после исправления — в 30. Отдельно проверен handoff срока конкретного заказа, которого нет в справочнике. Эти числа описывают только синтетический набор. Тест калибровки grader показывает ложное принятие: правильная цена и цитата не мешают добавить неподтверждённое обещание бесплатного ремонта. Проверка схемы не объявляется проверкой всего смысла.

TaskStore сохраняет владельца, payload, версию и разрешение в SQLite. Проверены чужой владелец, запрет self-review, снятие approval после правки, отмена, повтор execute и открытие checkpoint новым процессом. Создаётся только локальный ticket; внешних сообщений или финансовых действий нет. Reviewer в CLI имитируется кодом и не является системой входа преподавателя.

Проверки: 119 тестов Академии, отдельный 30-case benchmark, браузерная работа помощника и все 48 страниц новых занятий, загрузка ZIP, checkpoint CLI и сборка. [Текущее наполнение](content-status.md) формируется из каталога. Рабочая Supabase не менялась.

Экспорт нужного пакета: `npm run academy:content -- --actor=TELEGRAM_ID --course=AG-101` (либо AG-201/AG-301). Укажите реального администратора, проверьте SQL и backup перед применением. Экспорт не выполняет SQL автоматически.
