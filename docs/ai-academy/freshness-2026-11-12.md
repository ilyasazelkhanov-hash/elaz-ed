# Обновление практики ENG-201 и AG-301 · 12 ноября 2026

## Что включено

- ENG-201-M2-L4: HTTP-авторизация удалённого MCP, независимые проверки issuer, audience, scope и срока, границы Origin и session ID. Версии протокола и SDK не смешиваются с версией существующего stdio-примера.
- AG-301-M2-L2: явное согласие на актуальное предложение после синтетического события завершения воспроизведения; прерывание, изменение версии и истечение срока снимают основание для действия.
- AG-301-M3-L2: поздний handoff не создаёт согласия; повтор исполнения не создаёт второй локальный результат. Однопроцессная модель не обещает распределённой идемпотентности.
- Сохранены 16 уроков в каждом курсе, прежние коды и исходная практика. Добавлены критерии, вопросы квиза ENG-201 и конкретные ссылки на первоисточники.

Лаборатории: `content/ai-academy/projects/mcp-authorization-lab` и `voice-confirmation-lab`. Скачиваемые ZIP находятся в `public/learning/academy/`. Они собираются из исходников детерминированно при `npm run academy:labs` и `npm run academy:content`, без внешних зависимостей. Архивы включают упражнения, тесты и атрибуцию.

## Честные границы

Оба упражнения автономны: Node.js 24, без установки пакетов, настоящих токенов, модели, микрофона, внешней отправки и платежей. Авторизация получает синтетическое условие проверки токена, а голосовая модель получает синтетические события. Это не JWT-валидатор, HTTP/OAuth middleware, MCP-сервер, аудиодетектор, доказательство личности или готовая защита production.

Новые источники расширяют практику; они не доказывают, что старые детерминированные упражнения перестали работать. Курс по-прежнему отдельно обозначает legacy-протокол 2025-03-26 в stdio fixture.

## Воспроизводимая проверка

```sh
npm ci
npm run academy:content
npm run test:course-freshness
npm run test:all
npm run build
```

Отдельные лаборатории запускаются без npm: `node --test` и `node demo.mjs` в распакованной папке. `test:course-freshness` проверяет обе модели, соответствие ZIP исходникам, интеграцию уроков/книг/читателя и отсутствие ключей ответов в публичных материалах.

Для отдельной браузерной проверки подготовлен `scripts/course-freshness-browser.cjs`: локальные dev/preview на портах 5173/5180, Playwright и Chromium; API синтетический, без обращения к рабочей базе. В среде подготовки Chromium не запустился (`socket() failed: Operation not permitted`), поэтому визуальная проверка этим пакетом не подтверждается. Сценарий проверен синтаксически, но его результаты ещё необходимо получить в доступном браузерном runtime.

Перегенерация также синхронизирует книги с уже существующими ссылками на учебные скриншоты. В остальных курсах авторский текст не изменён; revision материалов обновлён общей версией каталога.

## Публикация

Сохранение в main, успешная сборка интерфейса и публикация уроков в Supabase — разные этапы. Этот пакет не выполняет миграции или импорт в рабочую базу. Для базы нужен отдельный проверенный выпуск через существующие валидаторы с baseline и подтверждённой возможностью восстановления. Для сайта проверяют commit и content revision реально обслуживаемой версии, а не только запись об успешной сборке.
