# Курсы AI Academy

**[Открыть программы курсов](https://elaz-ed.vercel.app/academy)** · **[Смотреть видео](https://elaz-ed.vercel.app/learning/academy/videos/index.html)** · [Файлы MP4 в репозитории](../../public/learning/academy/videos)

В репозитории готовы **112/112 модулей** и **448/448 занятий**. Открой курс, затем модуль: там сами объяснения, практика, подсказки и файлы, а не только отчёт о работе.

Отдельные новые модули доступны для чтения сразу. В учебный каталог включаются полностью готовые курсы.

Материалы для чтения находятся ниже. Полноценное обучение с сохранением прогресса и проверкой работ требует публикации в рабочую базу мини-аппки; оно ещё не подтверждено. [Техническое состояние и публикация](main-mini-app.md).
