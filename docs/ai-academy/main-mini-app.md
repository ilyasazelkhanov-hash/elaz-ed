# AI Academy в основной мини-аппке

Раздел входит в основной интерфейс OG: на главном экране есть 28 карточек курсов с локальными иллюстрациями и кнопка «Все курсы». Старый `VITE_ACADEMY_ENABLED` больше не скрывает раздел. Это дополнение к существующим OG-курсам.

Карточка открывает программу внутри приложения, включая маршрут, примеры, подсказки и занятия. Переход сохраняется в `#/academy/courses/CODE`, поэтому обновление страницы возвращает к программе. Запуск из Telegram поддерживает `startapp=academy` и `startapp=academy_ENG-201`; имя бота берётся из действующей настройки проекта.

На главном экране рядом с курсами есть кнопка «Видео». В Academy доступны галерея из пяти готовых MP4 и ссылка «Читать модули» на тексты в GitHub. Для двух творческих занятий и одного практикума видео также встроены рядом с материалом. Ролики подписаны по назначению: три демонстрации продукта и два учебных примера, не полный набор видеолекций.

## Доставка материалов

В Telegram чтение уроков, зачисление, проверка работ и прогресс используют существующий `/academy` API с подписанным `initData`. Готовые тексты и ответы квизов не включаются в публичные production-ресурсы. Готовы все 28 авторских курсов: 112 модулей и 448 занятий с практикой, критериями, подсказками и источниками. Тексты доступны в [списке модулей](README.md); состояние локального наполнения находится в [content-status.md](content-status.md). Публикация в рабочую базу ещё не выполнена.

Если сервер недоступен, не настроен либо ещё не содержит curriculum, каталог и страницы курсов показывают публичную программу с явной пометкой. Этот режим не создаёт зачисление, оплату, работы или прогресс. Повторная загрузка снова обращается к серверу. Отказы авторизации 401/403 сохраняются. Публичные данные генерируются по списку разрешённых полей из составленного учебного каталога: названия и результаты обновляются из готовых курсов, учебные тексты и ключи исключаются.

## Публикация в существующую Supabase

Для облачной среды сохранены домены `elaz-ed.vercel.app`, `dcdepwdxvadhludnubis.supabase.co`, `api.supabase.com` и требование защищённого `SUPABASE_ACCESS_TOKEN` для Management API. Сохранение черновика не применяет настройки к работающей среде. Значение токена вводится только в защищённых настройках среды, не в чат. Сохранённый черновик нужно просмотреть и сохранить в настройках, затем опубликовать среду; сам вызов сохранения конфигурации этого не делает.

Проверка без изменений данных:

```bash
npm run academy:release -- --check
```

Экспорт файлов SQL с существующим Telegram ID администратора:

```bash
npm run academy:release -- --actor=YOUR_TELEGRAM_ID
```

Файлы появляются в игнорируемой папке `content/ai-academy/generated/release`. Для одного готового курса добавьте `--course=ENG-201`. После проверки экспорта публикация выполняется тем же вызовом с `--publish`.

Команда использует сетевой прокси среды через Node.js 24 (`--use-env-proxy`), проверяет действующую роль администратора, делает preview импорта, затем вызывает существующие валидаторы Academy. Она не запускает `db push`, не восстанавливает журнал миграций и не заменяет вручную изменённый контент. Первые Core/VC-101 используют совместную квитанцию прежнего пакета, следующие курсы — отдельные. Уже применённый неизменённый пакет повторно не записывается; конфликт с ручной редактурой останавливает операцию. Отдельные курсы фиксируются независимо, поэтому при ошибке предыдущие успешные шаги сохраняются. Фактическую историю схемы см. в [отчёте выпуска](../RELEASE-2026-10-19.md).

После публикации проверьте подписанный вход из Telegram, зачисление и получение урока обычным учеником. Приватные вложения отдельно требуют bucket из контракта API; тексты и постоянные ссылки на работы работают без загрузки файлов.

## Проверки изменения

- Production build: TypeScript, Vite, 38 публичных страниц.
- `npm run test:academy`: 170 проверок, включая защиту авторизации и генерацию публичной программы.
- Браузерная проверка production-сборки использует синтетический Telegram-контекст и локальный API fixture. Проверены все 28 карточек, раскрытие полного каталога, зачисление, первый урок и восстановление после перезагрузки на ширинах 320/390/1024 px; галерея из пяти видео, открытие MP4 через Telegram SDK и корректные абсолютные ссылки; ошибок JavaScript нет. Это не проверка рабочего Telegram/Supabase.

В текущей среде запросы к рабочему Vercel и Supabase отклоняются сетевым прокси с 403; токен Supabase не предоставлен. Публикация на сервер и проверка рабочего deployment этим изменением не подтверждены.
