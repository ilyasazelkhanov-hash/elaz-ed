# Курсы основной мини-аппки и демо Академии

Основные разделы OG — **«Главная / Рейтинг / Профиль»**. На главной сразу видны уровень, XP, стрик и бонус дня, ниже — курсы и блог. У курсов анимированные обложки. [Текущее исправление и проверки](../fixes/2026-10-28-gameplay-and-materials.md). В основном обучении 28 программ, 112 модулей и 448 авторских занятий с текстами, примерами, изображениями и практическими файлами.

Главный каталог: `/#/courses`. Программа: `/#/courses/CORE-000`. Занятие: `/#/courses/lessons/CORE-000-M1-L1`. Моё обучение: `/#/courses/my-learning`, также доступно из профиля. Telegram: `startapp=courses` или `startapp=course_ENG-201`.

**Академия — отдельное демо**: `/#/academy`. В публичной сборке доступен только первый вводный модуль Core, четыре занятия. Демо работает локально от имени учебного пользователя, без административных прав, не вызывает рабочий учебный API и использует отдельный ключ хранилища `og:academy:sample:v1`. Настоящие зачисления, работы и результаты не меняются. Для локального предпросмотра основных курсов используется другой ключ `og:courses:preview:v1`; рабочие результаты остаются на сервере.

[Экран основного урока](screens/main-courses-lesson.png) · [Отдельное демо](screens/academy-isolated-demo.png). Скриншоты локальной production-сборки с синтетическим API, не подтверждение рабочей выкладки.

Старый числовой каталог OG скрыт с главной и из рекомендаций. Его записи, оплаты, доступы и прогресс не удалены. Старая ссылка на курс у обычного пользователя показывает сообщение и переход к актуальному каталогу; администратор сохраняет доступ к редактору старых записей.

Пять ранее созданных демороликов, их постеры и субтитры удалены из публичной сборки. Кнопка «Видео», галерея и встроенные демоплееры убраны. Внешние проверенные первоисточники и учебные иллюстрации сохранены.

**Чтение:** все 448 уроков доставляются вместе с frontend, отдельной книгой JSON для каждого курса. Открытие материала не требует публикации учебных пакетов в Supabase. **Зачёт:** зачисления, сдача работ, оценки и официальный прогресс по-прежнему требуют защищённого серверного API. Чтение само по себе не начисляет XP и не отмечает урок пройденным.

## Первые курсы и новый экран урока

AI Core и VC-101 дополнены 32 отдельными разборами для начинающего. Для всех 112 модулей подготовлены вымышленные мини-кейсы и схемы: данные, три действия, наблюдаемый результат, ошибка и проверка. Открытые учебные блоки входят в отдельные книги для чтения; каталог содержит только метаданные. В демо явно выбран только первый вводный модуль. Грейдинг и доступ не менялись.

В новом экране материал идёт перед подсказками, практика и сдача работы собраны вместе. В браузерной проверке пяти форматов объяснение начиналось на 441–496 px от начала основного скролла при высоте705 px, ранее примерно1961–2073 px. Это измерение локальной production-сборки с синтетическим API, не аналитика реальных учеников.

Добавлены офлайн-тетрадь CORE, готовый локальный пример VC-101 и отдельный React/Vite-каркас с lockfile. [Инструкция и экраны](first-courses.md). Редактору: `npm run academy:enrich` обновляет авторские блоки из `examples/` и `lesson-explainers/`, затем `npm run academy:content` генерирует каталоги, схемы и книги. Обогащение не меняет задания, ключи квизов или критерии.

## Порядок и наглядные примеры

Все 448 занятий имеют номер внутри курса (например, 5 из 16) и модуля (2.1). Программа упорядочена по позициям; отмечает пройденные занятия и следующий непройденный. В уроке видны текущий модуль, соседние занятия с названиями и переход между модулями. Переход не меняет зачёт и не обходит доступ.

Добавлены 112 схем модулей и 24 скриншота учебных примеров для 91 занятия во всех 28 курсах. В мини-аппке скриншоты увеличиваются в диалоге с клавиатурным управлением. На GitHub те же изображения, номера и переходы включены в страницы модулей. [Инструкция с экранами](how-to-learn.md).

Источники: `lesson-visuals.json`, собственные локальные проекты и четыре ранее снятых design-экрана. Воспроизведение: `node scripts/academy-screenshots.cjs`; скриншоты навигации — `node scripts/academy-navigation-screenshots.cjs` при запущенном Vite. Схемы обновляются при `npm run academy:content`.

## Доставка материалов

Открытые материалы: `/learning/courses/materials/CODE.json`; урок: `/#/courses/read/CORE-000-M1-L1`. Книги загружаются по необходимости, включают объяснения, примеры, схемы, ссылки и практику. Генератор `scripts/course-materials.mjs` разрешает только опубликованные бесплатные авторские курсы без связи со старым платным каталогом. В текущем корпусе это все 28 курсов.

Разрешённые поля перечислены явно. В книги не попадают ключи квизов, задания серверного оценивания, рубрики, данные учеников и произвольные служебные поля. Защищённые запросы не подменяются публичными данными: отказы 401/403 сохраняются. При недоступном API доступно чтение, а сдача и зачёт обозначены как недоступные. Академия остаётся отдельным демо четырёх вводных занятий.

## Публикация в существующую Supabase

Для облачной среды сохранены домены `elaz-ed.vercel.app`, `dcdepwdxvadhludnubis.supabase.co`, `api.supabase.com` и требование защищённого `SUPABASE_ACCESS_TOKEN` для Management API. Сохранение черновика не применяет настройки к работающей среде. Значение токена вводится только в защищённых настройках среды, не в чат. Сохранённый черновик нужно просмотреть и сохранить в настройках, затем опубликовать среду; сам вызов сохранения конфигурации этого не делает.

Проверка без изменений данных:

```bash
npm run academy:release -- --check
```

Экспорт файлов SQL с существующим Telegram ID администратора:

```bash
npm run academy:release -- --actor=YOUR_TELEGRAM_ID
```

Файлы появляются в игнорируемой папке `content/ai-academy/generated/release`. Для одного готового курса добавьте `--course=ENG-201`. После проверки экспорта публикация выполняется тем же вызовом с `--publish`.

Команда использует сетевой прокси среды через Node.js 24 (`--use-env-proxy`), проверяет действующую роль администратора, делает preview импорта, затем вызывает существующие валидаторы Academy. Она не запускает `db push`, не восстанавливает журнал миграций и не заменяет вручную изменённый контент. Первые Core/VC-101 используют совместную квитанцию прежнего пакета, следующие курсы — отдельные. Уже применённый неизменённый пакет повторно не записывается; конфликт с ручной редактурой останавливает операцию. Отдельные курсы фиксируются независимо, поэтому при ошибке предыдущие успешные шаги сохраняются. Фактическую историю схемы см. в [отчёте выпуска](../RELEASE-2026-10-19.md).

После публикации проверьте подписанный вход из Telegram, зачисление и получение урока обычным учеником. Приватные вложения отдельно требуют bucket из контракта API; тексты и постоянные ссылки на работы работают без загрузки файлов.

## Проверки изменения

- Production build: TypeScript, Vite, 38 публичных страниц.
- `npm run test:academy`: 198 проверок, включая защиту авторизации и генерацию публичной программы.
- Браузерная проверка production-сборки использует синтетический Telegram-контекст и локальный API fixture. Проверены все 28 карточек, раскрытие полного каталога, зачисление, первый урок и восстановление после перезагрузки на ширинах 320/390/1024 px; отдельное демо и отсутствие запросов к удалённым демовидео; ошибок JavaScript нет. Это не проверка рабочего Telegram/Supabase.

В текущей среде запросы к рабочему Vercel и Supabase отклоняются сетевым прокси с 403; токен Supabase не предоставлен. Публикация на сервер и проверка рабочего deployment этим изменением не подтверждены.


## Проверка разделения

`node --experimental-transform-types --no-warnings scripts/main-courses-browser.cjs` проверяет 28 карточек в основном каталоге, чтение и перезагрузку урока, скрытие старых курсов, изолированное демо даже для администратора и отсутствие запросов к удалённым видео. У демо ноль запросов к рабочему учебному API; состояние основного обучения не меняется. Проверены ширины 320/390/1024.

Публичные страницы программ перенесены на `/courses`, `/courses/CODE` и `/courses/directions/CODE`. Старые внешние ссылки `/academy/courses/CODE` и `/academy/directions/CODE` перенаправляются в новый раздел. Проверка сертификатов и портфолио сохраняет прежние адреса.
