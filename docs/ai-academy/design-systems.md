# Дизайн интерфейсов · DS-101 / DS-201 / DS-301

Добавлены 48 авторских занятий: задача человека, прототип, формы и доступность, исследовательское evidence, библиотека, перенос в код, визуальные проверки и управление дизайн-системой. Каждое занятие содержит объяснение, практику, критерии и подсказку. Квизы не раскрывают ключи в клиентском payload; итоговые работы проверяются по рубрике. Актуальная полнота всей Academy находится в [content-status.md](content-status.md).

Проект `content/ai-academy/projects/design-lab` — пять работающих экранов вымышленной мастерской. Есть ошибки выбора и email, исправление, сохранение текста при возврате, review и учебное подтверждение. Данные остаются в памяти вкладки, настоящая заявка не отправляется. Сбор учебных событий выключен по умолчанию. Варианты A/B отличаются подписью перехода; их полезность требует исследования.

Прототип проверяется реальным браузером: клавиатурное подтверждение, фокус ошибки, сохранение полей, viewport 320/390/1024 px и отсутствие горизонтального переполнения. Включены девять реальных скриншотов состояний. Повтор review даёт нулевой пиксельный diff, A/B-пара — ожидаемое изменение, которое требует ручного решения. Метаданные PNG не создают разницу; большие маски отклоняются.

`research.mjs` исключает внутренние записи до создания контекста и отклоняет отсутствующие цитаты. Интерпретация проверяется человеком. Три публичные заметки синтетические, они не заменяют настоящие добровольные сессии. Для зачёта исследовательской практики нужны фактические наблюдения с понятным согласием.

`quality.mjs` измеряет контраст, проверяет связь замечаний с измерениями, считает confusion matrix и отклоняет устаревшее evidence. В агентном упражнении используются шесть макетов предложений; оценка валидатора не выдаётся за качество настоящей LLM. Живой vision/LLM API не подключён, автоматического изменения продукта нет. Проверки не являются полной сертификацией WCAG.

Архив: `/learning/academy/design-lab.zip`. Основные шесть Node-тестов не требуют сторонних зависимостей. Необязательная пересборка снимков использует отдельный lockfile Playwright 1.62.1 и системный Chromium. `npm run test:academy` включает проверки контраста, цитат, PNG, масок, замечаний и версии evidence; `npm run build` валидирует пакеты и собирает приложение. Публикация в Supabase описана в [main-mini-app.md](main-mini-app.md).
