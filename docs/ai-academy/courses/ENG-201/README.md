## Как идти по курсу

Всего 16 уроков. Порядок: модуль 1 → 2 → 3 → 4. В каждом модуле сначала урок .1, затем .2, .3 и .4. Например, после 1.4 идёт 2.1 — урок 5 курса. Переходы внизу каждого занятия ведут к следующему шагу.

Изучи пример, выполни практику и проверь результат по критериям. Открытие следующей страницы не отмечает предыдущий урок пройденным.
