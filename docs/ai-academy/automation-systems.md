# AU-201 и AU-301: интеграции и эксплуатация

Два пакета содержат 32 авторских занятия с объяснениями, примерами, практикой и критериями. AU-201 ведёт через HTTP, JSON, пагинацию, нормализацию заявок, маршрутизацию, ошибки и передачу процесса. AU-301 разбирает согласованность, аренду обработчика, устаревший результат, повторы, dead-letter, circuit breaker, доступы, наблюдение и стоимость.

Общий проект: `content/ai-academy/projects/automation-lab/`. Студенческий архив: `public/learning/academy/automation-lab.zip`. На Node 24 он запускается без внешних зависимостей. Браузерный интерфейс показывает семь сценариев, а двенадцать проверок выполняются командами из README проекта.

Проверены настоящие локальные HTTP-запросы, ограниченные повторы, Retry-After, таймаут, цикл пагинации, минимизация полей, конфликт ID, восстановление SQLite после открытия, владение арендой и отказ старому номеру attempts даже при повторном захвате тем же worker. Вымышленный бюджет отдельно проверяет единицы за миллион токенов и фиксированные расходы.

Стенд не вызывает внешнюю CRM, email, Telegram, OAuth-провайдера или модель. Известный заголовок training-only имитирует контракт, а не рабочую безопасность. Browser backoff использует логические задержки без реального ожидания. Circuit breaker — модель одного процесса. Система ролей, внешняя доставка, кластер и backup остаются предметом проектных упражнений и не заявлены реализованными в стенде.

Браузерная проверка прошла семь сценариев и все 32 страницы занятий. Сборка, 109 тестов Академии и экспорт каждого пакета поверх прежних курсов прошли. [Актуальное наполнение](content-status.md) формируется из каталога.

Для серверного экспорта используется `npm run academy:content -- --actor=TELEGRAM_ID --course=AU-201` либо AU-301. Реальный ID администратора, проверка SQL и backup нужны перед применением. Экспорт не подключается к рабочей базе.
