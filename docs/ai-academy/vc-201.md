# VC-201 · полный путь от интерфейса до SQLite

16 занятий наполнены авторскими объяснениями, практикой, подсказками и критериями. Учебный проект находится в `content/ai-academy/projects/VC-201/`, архив для студента — `public/learning/academy/vc-201-starter.zip`. Ссылка есть в каждом занятии.

Node.js 24 запускает проект без установки зависимостей. Пример содержит HTTP-сервер, браузерный клиент, SQLite, регистрацию и вход с scrypt, ограниченные по времени сессии, чтение только собственных записей, уникальность слота и повторяемые запросы с ключом. Запись и черновик уведомления создаются одной транзакцией. Доставка уведомления отсутствует и не заявляется интерфейсом.

Четыре интеграционных теста проверяют доступ, конфликт слота, повтор запроса, неверные данные, размер тела запроса, сохранение после перезапуска и наличие черновика outbox. Браузерная проверка проходит регистрацию, создание записи и выход. Отдельно открыты все 16 занятий Академии и проверена загрузка ZIP.

Официальные справочники Node.js SQLite и crypto проверены 26 октября 2026 года. Это локальный стенд с синтетическими данными и расписанием января 2030 года. Для эксплуатации с реальными клиентами отдельно нужны HTTPS, ограничение запросов, управление сессиями, миграции и backup.

Курс подключён к `npm run academy:content`. [Текущее наполнение Академии](content-status.md) формируется из каталога. Серверный экспорт только VC-201:

```bash
npm run academy:content -- --actor=TELEGRAM_ID --course=VC-201
```

Вместо TELEGRAM_ID указывается реальный администратор. Экспорт не применяет SQL к рабочей базе. Добавление VC-201 поверх прежних трёх курсов проверено в локальном PostgreSQL; повтор не меняет версии, конфликт с ручными правками останавливает транзакцию.
