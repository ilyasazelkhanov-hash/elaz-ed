# Понятный маршрут по AI Academy

Для всех 28 курсов добавлены объяснение простым языком, отдельная учебная ситуация, первый шаг, разобранный пример, три критерия самопроверки и типичная ошибка. Результаты четырёх модулей показаны рядом, чтобы до записи было понятно, к чему ведёт программа.

Карточки и страницы курсов используют десять собственных SVG-иллюстраций по направлениям. Они лежат в `public/learning/academy/`, открываются без сторонних сервисов и восстанавливаются командой `node scripts/academy-illustrations.mjs`. Под иллюстрацией находится текстовая схема из трёх шагов; изображение декоративное, а смысл доступен через обычный текст.

Каждое занятие получает цель, три раскрываемые подсказки, запрос к AI для самостоятельного разбора, личную самопроверку и краткие объяснения терминов. Формат подсказки зависит от типа занятия: чтение, повторение демонстрации, практикум, разбор случая, квиз или защита. Подсказки не читают ключи ответов. Для опубликованного занятия используются его фактический результат и критерии.

Подготовка к занятиям в статусе `outline` строится из метаданных, которые уже возвращает страница курса. Тело неопубликованного урока не раскрывается. Запись на такой курс остаётся листом ожидания, а завершение урока по-прежнему запрещено сервером. Локальные галочки самопроверки не заменяют зачёт. Кнопка продолжения опубликованного курса выбирает первое ещё не завершённое опубликованное занятие по сохранённому прогрессу.

## Где редактировать

- `content/ai-academy/course-guides.json`: 28 отдельных пояснений и примеров.
- `src/lib/academy-guidance.ts`: подсказки по формату, словарь и выбор следующего занятия.
- `src/screens/academy/Guidance.tsx`: учебный маршрут и раскрываемая помощь.
- `tests/academy-guidance.test.mjs`: покрытие 28 курсов и 448 метаданных занятий, отсутствие утечки контента и ключей, выбор следующего шага.

## Готовность контента

Подсказки сами по себе не меняют статусы публикации. [Актуальный список наполненных курсов и оставшихся занятий](content-status.md) формируется из учебного каталога. Пояснения к программам и подготовительные подсказки не заменяют авторские лекции, практику и оценивание.

Серверное наполнение и включение Academy в рабочем Telegram-приложении требуют порядка из `authored-content.md` и `backend-contract.md`. Изменение интерфейса не применяет миграции, не включает production-флаги и не создаёт рассылки.

## Проверки

`npm run build` проверяет TypeScript, собирает приложение и 38 публичных страниц программы. `npm run test:academy` включает новые тесты; `npm run test:api` и `node --test tests/learning-paths.test.mjs` проверяют существующие контракты и переносимость учебных маршрутов. Браузерная проверка дополнительно проходит все страницы курсов на узком телефоне и большом экране, подготовку к неопубликованным занятиям с правами студента, копирование подсказки и продолжение после завершённого урока.

Проверено в этой среде: сборка и 38 публичных страниц; 73 теста Academy, 79 API-проверок, 8 проверок SQL-квизов, 3 проверки личного маршрута и 3 проверки практических курсов. Chromium прошёл 84 просмотра страниц курсов (28 × 3 ширины: 320/390/1024 px) и 26 подготовительных занятий с правами студента. Дополнительно проверены буфер обмена, самопроверка, отправка работы, учебное ревью и переход с CORE-000-M1-L1 на CORE-000-M1-L2 после зачёта. Ошибок JavaScript не обнаружено.
