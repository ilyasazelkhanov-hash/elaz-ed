# AI Academy — отчёт реализации

18 октября 2026. Локальная интеграция в действующий OG CRE8R²; стек, старые уроки, пользователи и начисления не заменялись.

## Работающая система

- Ленивый раздел академии: вход с главной OG, deep/hash links, внутренняя навигация и кнопка Telegram «Назад», темы OG, reduced motion, мобильная адаптация.
- Каталог 9 направлений и отдельного AI Core, 28 курсов по уровням, поиск/фильтры, программа модулей/занятий, результаты, требования, итоговый проект и честный статус готовности.
- Зачисление/лист ожидания; после публикации участник может начать курс. Prerequisites, опубликованность всех предков и активный доступ проверяются сервером, в том числе при отправке ранее начатой работы.
- Составные занятия: Markdown, код, видео/файл/ссылка, чеклист и практика. Форматы включают микролекцию, демонстрацию, лабораторную, кейс, воркшоп, задание, квиз, защиту, справочник.
- Серверный прогресс обязательных занятий; квиз с одним/несколькими ответами, коротким текстом и кодом по эталону, снимком правил/вопросов и лимитом попыток. Пользовательский код не исполняется. Клиент не назначает оценку.
- Практика текстом/HTTPS-ссылкой и приватными файлами: черновик → отправка → доработка → новая версия → независимая оценка по сохранённой рубрике и критическим критериям. Старые отзывы сохраняются.
- Роли редактора/преподавателя, назначения проверяющих, очередь работ, подтверждение входного портфолио, запрет самооценки.
- Подтверждение завершения только после обязательных занятий и принятого итогового проекта; непрозрачный код и публичная проверка без данных участника.
- Источники с многократными связями, языковыми/типовыми фильтрами, таймкодами и пагинацией. Неутверждённые внутренние ссылки скрыты от учеников.
- CMS сущностей и блоков: создание, редактирование, архивирование, drag-and-drop и клавиатурный reorder, публикационные проверки, optimistic version, источники/связи, роли, журнал before/after.
- Импорт нормализованного JSON в CMS: preview без записи → отчёт → явное применение. CLI валидирует исходный curriculum и готовит импорт/SQL с dry-run по умолчанию. Повтор сохраняет ручные правки.
- Используется прежний `/academy` endpoint в существующей Edge Function с проверкой Telegram. Прямой доступ anon/authenticated к таблицам и RPC закрыт. Ключи ответов, редакторские заметки и чужие работы не возвращаются ученику.

## Подключение боевого окружения

1. Backup и применение на стенде по порядку: `20261018080000_ai_academy.sql` → `20261018150000_ai_academy_completion.sql` → `20261018170000_ai_academy_files.sql`. Существующие миграции OG, включая `006_courses_stars_freezes.sql`, должны быть применены. Затем релиз обновлённой существующей Edge Function `api`; проверить приватный bucket `academy-private`.
2. Проверить импорт под реальным Telegram ID администратора: dry-run, затем применение. CLI экспортирует SQL, но сам к базе не подключается.
3. Включить `VITE_ACADEMY_ENABLED=true` после проверки и пересобрать фронтенд. Адрес прежний: `<VITE_API_URL>/academy`.
4. Подготовить собственные материалы/проверки/рубрики и провести утверждение/публикацию. Для источников подтвердить доступность, права, атрибуцию и дату проверки.
5. Проверить настоящие Telegram-сессии трёх ролей на тестовом боте, safe areas и клавиатуру iOS/Android.

Облако, действующие пользовательские данные, сообщения, платежи и Git remote не изменялись. Сначала можно отключить feature flag, сохранив прежний OG; откат БД — через проверенный backup/recovery, без автоматического удаления aa_*.

## Закрытые пункты расширения

- N:M-матрица компетенций, редактирование связей и освоение только по фактическому серверному прогрессу обязательных занятий.
- Общий банк блоков с неизменяемыми версиями, утверждением и закреплёнными ссылками. Снимки завершений не меняются при последующих правках.
- Привязка к существующим Stars-продуктам. Счёт идёт через действующий платёжный путь OG; сервер повторно проверяет доступ после покупки и возврата.
- Приватное хранилище: подписанная загрузка, проверка размера/MIME/байтов, finalize перед прикреплением, скачивание владельцем или назначенным преподавателем. Прямого публичного доступа нет.
- Публичное портфолио только принятой работы по явному согласию, отзыв публикации. Вложения, отзывы, пользовательские идентификаторы и ссылки с query/fragment не публикуются.
- Публичные страницы /academy/verify/:code и /academy/portfolio/:slug работают без Telegram-входа; endpoint ограничен двумя действиями и частотой запросов.
- RU/KK/EN для интерфейса и авторских переводов с fallback RU. Переводы учебных текстов вводит автор; автоматический перевод всех 448 планов не выдаётся за готовый контент.
- Воронка реальных событий, неактивность в конкретном курсе и медианное время до первого результата. Агрегаты не содержат ответов, работ и профилей.
- 38 статических публичных страниц программы: каталог, 9 направлений, 28 курсов. HTML содержит безопасные метаданные и названия программы; закрытых материалов нет. Кнопка ведёт в приложение.

## Границы локальной поставки

В исходном seed 448 планов; локальный учебный пакет наполняет первые 32 занятия, остальные 416 остаются планами. Публикация серверного учебного пакета выполняется отдельно по authored-content.md. Загружаемые PDF/ZIP проверяются по формату, но антивирусная проверка содержимого не заявляется.

Все серверные возможности подготовлены в исходниках и проверены локально. Миграции, Storage и обновлённая Edge Function ещё не применялись в облаке. Настоящие платежи Stars и физические устройства Telegram требуют проверки на отдельном тестовом боте после развёртывания.
