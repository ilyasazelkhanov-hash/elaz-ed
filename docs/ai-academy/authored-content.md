# Учебный контент и визуал Academy · 19 октября 2026

В локальном демо доступны два наполненных курса: AI Core и «Первое приложение с AI» (VC-101), по 16 занятий. Это около 8 500 слов основного текста, отдельные примеры кода, упражнения, тесты, критерии практики и итоговые работы. Остальные 416 занятий остаются планами. Готовые курсы показаны первыми; полный перечень программ раскрывается отдельно.

VC-101 ведёт через один продукт — мобильный прототип мастерской. В уроках есть полный React-компонент, CSS и тест Playwright. Учебная заявка сохраняется локально; интерфейс прямо сообщает, что мастеру она не отправлена. Пример действительно собран и проверен в браузере. Для настоящего приёма заявок понадобится сервер, это указано в материале.

Core объясняет выбор задач, контекст, ограничения моделей, проверку результатов, стоимость и работу с источниками. Материалы связываются с 19 проверенными официальными источниками. Чужие лекции и видео не перепечатаны; просмотр видео из пользовательской подборки не заявляется. Даты проверки сохранены у источников.

Сейчас Academy работает на русском: переключатель языка скрыт и в приложении, и на публичных страницах подтверждений и портфолио. Старые значения KK/EN в localStorage не меняют язык и не перезаписываются. Переводы интерфейса и авторские переводы материалов сохранены. Для будущего запуска трёх языков достаточно установить `VITE_ACADEMY_MULTILINGUAL=true` и пересобрать приложение; по умолчанию флаг выключен. Если авторского перевода нет, остаётся русский текст.

## Где менять

- `content/ai-academy/authored/CORE-000.json` и `VC-101.json`: уроки, практика, вопросы и первоисточники.
- `scripts/academy-content.mjs`: валидация и сборка `catalog.learning.json` поверх исходного curriculum. Короткие заглушки не проходят проверку. Исходный `catalog.normalized.json` остаётся нетронутым.
- Обычная практика и финальная защита используют разные рубрики. Критерии практики относятся к заданию конкретного занятия.
- Каталог использует материалы OG: градиенты, узоры, объёмные эмодзи, отклик на касание. Уменьшение анимации учитывается. Высота CTA зависит от текста, длинные RU/KK/EN подписи переносятся.

## Обновление и запуск

`npm run academy:content` собирает локальный контент. `npm run build` выполняет этот шаг автоматически. В браузере демо обновляет исходные планы и нетронутые версии учебного пакета, сохраняя зачисления, результаты и ручные изменения. Изменённые вопросы получают новую версию: старый зачёт не подменяет новую проверку.

Полные уроки и ключи тестов включены в локальный Vite dev. Production-сборка по умолчанию исключает их из клиентских демо-ассетов: рабочее приложение получает разрешённые материалы через сервер. `VITE_ACADEMY_PUBLIC_DEMO=true` предназначен только для отдельной заведомо публичной демонстрации — этот флаг публикует учебный пакет. HTML-превью в обоих режимах содержат только программу.

Для серверного наполнения сначала импортируется исходный curriculum и применяются три миграции Academy. Затем `npm run academy:content -- --actor=TELEGRAM_ID` создаёт `content/ai-academy/generated/authored-content.sql`. Команда не подключается к базе. SQL требует реального ID администратора, проходит существующие валидаторы draft → approved → published, выполняется транзакционно, повтор той же редакции ничего не меняет. При наличии отредактированных строк выдаёт конфликт; ручные материалы автоматически не заменяются. Перед применением нужны обычные проверка SQL и backup.

## Проверки

- `npm run test:academy`: учебные сценарии, сохранность ручных правок, версии тестов, различие рубрик, PostgreSQL-публикация пакета и повторный импорт.
- `node --experimental-transform-types --test tests/academy-locale.test.mjs`: русский по умолчанию, сохранность старого выбора, включение существующих переводов через флаг.
- `node Azelkhanov-master/tests/academy-authored-browser.mjs`: размеры экрана, открытие Core, содержательный урок и источники. Переключение RU/EN/KK проверяется при `VITE_ACADEMY_MULTILINGUAL=true`.
- `node Azelkhanov-master/tests/academy-example.mjs`: сборка именно кода из урока и проверка формы, выбранной услуги, честного подтверждения, перезагрузки и повреждённого localStorage.

Браузерные проверки используют локальный Edge и установленный Playwright соседнего мастера только как QA-инструмент. Рабочая сборка OG от мастера не зависит. Облачные данные, платежи и сообщения этим изменением не затрагивались.

Фактический итог проверки: 61/61 Academy; целевые content/SEO 6/6 после финального изменения пакета; TypeScript/Vite/prerender прошли. Browser: 320/360/390/768/1280 px, все три языка, отправка практики и сохранение после reload, без JS-ошибок. PostgreSQL-backed учебный цикл прошёл. Пример из VC-101: сборка и 5 браузерных проверок. В production-ассетах отсутствует catalog.learning с полными уроками/ключами.
