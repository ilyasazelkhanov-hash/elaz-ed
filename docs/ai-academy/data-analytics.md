# Аналитика данных · DT-101, DT-201, DT-301

Добавлены 48 авторских занятий трёх уровней. У каждого есть объяснение, работа на учебном наборе, ожидаемый результат, критерии, подсказка и ссылки на проверенные первоисточники. В каждом курсе есть квиз из трёх вопросов и итоговая защита проекта. Текущая полнота всей Academy формируется в [content-status.md](content-status.md); наличие пакета в Git не подтверждает публикацию в Supabase.

| Курс | Результат ученика |
| --- | --- |
| DT-101 | Исследовательский вопрос, журнал источников и преобразований, объяснимые графики и записка с ограничениями |
| DT-201 | Проверенные SQL/KPI, разбор JOIN и утечки будущего, рабочая панель с проверкой фильтров |
| DT-301 | A/B-протокол, оценка неопределённости, rolling backtest, контракт метрик и ограниченный SQL-инструмент |

Практика находится в `content/ai-academy/projects/data-lab`, архив для ученика — `/learning/academy/data-lab.zip`. Основной анализ и десять Python-тестов используют стандартную библиотеку; Matplotlib 3.10.8 нужен только для необязательной пересборки четырёх включённых графиков. Рисунки показываются прямо в соответствующих занятиях.

Лаборатория содержит 11 исходных строк заказов, из которых восемь проходят явный контракт очистки. Контрольные числа: выручка 13500 ₸, средний чек 1687,50 ₸, задержаны 4/8 заказов. Кратность JOIN показывает реальную ошибку: сумма заголовков после соединения вырастает до 20000 ₸. Проверяются также пропуски колонок, внешние ключи, недоступность приватной таблицы, запрет записи/ATTACH, лимиты запросов и устаревший отчёт.

A/B-агрегаты и временной ряд синтетические. Приблизительный интервал разницы групп пересекает ноль. Прогноз получает только доступный исторический префикс; тест изменяет будущие наблюдения и проверяет независимость первого прогноза. Оценка SQL разделяет разрешение на чтение и правильность ответа: разрешённый запрос может считать неверную метрику.

В source ledger десять ссылок на методику и инструменты, преимущественно документация CPython. Они не выдаются за независимые источники наблюдений о бизнесе. SQL-инструмент ограничен внутри доверенного процесса; это не отдельная операционная песочница или корпоративная система прав. Генерация запросов настоящей LLM не подключена: ученик может предложить запрос самостоятельно или через свой AI-инструмент, а затем проверить его.

Проверки: `npm run test:academy` включает запуск всех десяти Python-тестов; `npm run build` валидирует пакеты и собирает мини-аппку. В браузере отдельно проверяются 48 занятий, изображения и фильтр HTML-панели. Публикация в основную мини-аппку описана в [main-mini-app.md](main-mini-app.md).
