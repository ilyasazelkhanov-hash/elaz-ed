# Измерение ресурсов сборки

`scripts/perf-assets.mjs` измеряет готовый `dist`, не меняя приложение и не запуская сборку. Vite сохраняет граф зависимостей в `dist/.vite/manifest.json` через `build.manifest`.

```powershell
npm run build
node scripts/perf-assets.mjs --include App,Academy --out docs/performance/assets-current.json
```

`--dist` выбирает другую папку сборки. `--include` добавляет указанные ленивые чанки и их статические зависимости к ресурсам из `index.html`. Можно указать имя чанка без хеша (`Academy`) или точный ключ исходного модуля из манифеста. Отчёт записывается только при наличии `--out`; иначе JSON выводится в консоль.

`assets-baseline.json` снят 19 октября 2026 года с существовавшего `dist`, до изменений текущей оптимизации. В этой сборке ещё нет манифеста, поэтому статические JS-импорты определены по объявлениям в собранных файлах. Привязанный только к ленивым чанкам CSS в таком снимке не восстанавливается. Его нужно сравнивать по запросам браузера, а не по полю `selectedScenario.css`.

| Показатель исходной сборки | Байты | gzip, байты |
| --- | ---: | ---: |
| Весь выпущенный JS | 2 572 926 | см. JSON |
| Весь выпущенный CSS | 220 514 | см. JSON |
| Статический JS из HTML и его зависимости | 225 411 | 70 903 |
| CSS из HTML | 69 295 | 16 432 |
| JS для HTML + явно выбранных App, Academy | 679 915 | 218 274 |

`gzipBytes` — сумма размеров отдельных файлов, сжатых локально стандартным gzip. Это не сетевое измерение: CDN может использовать Brotli, а браузер — кеш. Статический граф также не включает дополнительные запросы, которые React запускает при открытии конкретного маршрута. Для времени первой отрисовки и фактического количества запросов нужен отдельный замер браузера.

## Сравнение после оптимизации

`assets-current.json` снят после успешной производственной сборки. Для выбранных App и Academy состав статических JS-чанков совпадает с исходным снимком: 31 файл с теми же логическими именами. Дополнительно старый разбор объявлений импортов проверен на новой сборке: он нашёл ровно тот же JS-граф, что и манифест Vite. Это позволяет сравнивать объём этого статического сценария; фактическую загрузку конкретного маршрута всё равно нужно измерять браузером.

| Показатель | До, байты | После, байты | Разница |
| --- | ---: | ---: | ---: |
| JS для HTML + App, Academy | 679 915 | 659 522 | −20 393 (−3,00%) |
| Тот же JS, сумма gzip | 218 274 | 211 211 | −7 063 (−3,24%) |
| Весь выпущенный JS | 2 572 926 | 2 553 067 | −19 859 |
| Статический JS из HTML | 225 411 | 225 411 | 0 |
| CSS из HTML | 69 295 | 69 295 | 0 |
| Весь выпущенный CSS | 220 514 | 220 514 | 0 |

В текущем `selectedScenario.css` учтён также ленивый `academy-*.css` размером 6 541 байт. Исходный снимок без манифеста не добавлял его в граф сценария, хотя этот файл уже присутствовал в исходной сборке. Разница этого поля не означает рост CSS. Имена с хешами и общий размер всех трёх CSS-файлов совпадают между сборками.

Все 12 наборов шрифтов также совпадают побайтно: проверены SHA-256, семейства, диапазоны весов и символов, `font-display` и размеры. Уменьшение JS в таблице не является измерением FPS, времени загрузки или сетевого трафика.

## Шрифты и сохранение оформления

Исходные импорты Fontsource сохранены. Onest использует все веса 100–900, Unbounded — 200–900; `font-display: swap` и сами файлы шрифтов не меняются.

В сборке присутствуют 12 начертаний по наборам символов: 11 внешних WOFF2-файлов общим размером 359 220 байт и один встроенный в CSS набор Unbounded Cyrillic-ext размером 1 840 байт до кодирования в base64. Поле `fonts.bytesIncludingEmbedded` равно 361 060 байтам. Встроенный шрифт уже входит в размер CSS, повторно прибавлять его к объёму загрузки нельзя.

Наличие файла в `dist` не означает его загрузку: `unicode-range` позволяет браузеру выбирать набор по тексту страницы. Поэтому удаление неиспользуемых на одном экране наборов не доказывает ускорение его загрузки. Наборы оставлены для сохранения оформления имён пользователей, авторского контента и будущих локалей: Cyrillic-ext содержит казахские буквы, Latin-ext — латинские буквы с диакритикой. Onest Math и Symbols нужны для встречающихся в контенте `∞`, `≈`, `≠`, стрелок и декоративных символов.

Отчёт содержит SHA-256 каждого файла шрифта, диапазоны символов и весов. Сравнение этих полей между сборками позволяет проверить, что оптимизация других частей приложения не изменила типографику.

Источники: [Fontsource: наборы символов и unicode-range](https://fontsource.org/docs/getting-started/subsets), [Fontsource: font-display](https://fontsource.org/docs/getting-started/display), [Vite: build.manifest](https://vite.dev/config/build-options.html#build-manifest).
