Команды мастера: `npm test`, `npm run test:server-types`, `npm run build`, `npm run test:concurrency -- --og-root ..`, `npm run test:ui`, `npm run test:touch`, `node tests/modules-browser.mjs`, `node tests/og-browser.mjs`. Команды OG: `npm run build`, `npm run test:api`, `npm run test:database`. Для браузерных проверок нужен работающий локальный dev-сервер и Playwright Chromium; `AZ_CHROME_PATH` позволяет указать свой исполняемый файл. Native PostgreSQL привязывается к 127.0.0.1 и останавливается после теста.

Машинные протоколы и изображения — в `test-results/`; они не включаются в генерацию клиента. OG пишет отдельный `test-results/og-independent-report.json` в своём корне. Предупреждение сборки о размере Three.js относится к отдельно загружаемому 3D-чанку; карты исходников выключены.

В итоговой мобильной проверке исправлено перекрытие кнопок диалога нижней навигацией: модальные окна вынесены через portal за пределы анимированного контейнера. После исправления редактор сохраняет материал и результат переживает перезагрузку.

Заголовки проверены на узком экране с широким шрифтом OG. Статическая 3D-сцена в режиме уменьшенной анимации перерисовывается после resize: смена ширины экрана больше не очищает иллюстрацию.

Генератор сохраняет общее ядро модулей, выбирая конфигурацию и контент; физическое удаление всего кода выключенных модулей не выполняется. Старый и новый XP в OG остаются раздельными. Это описано в README и руководстве интеграции OG.

## Проверить на стенде заказчика

Настроить отдельные бот, Supabase, домен, секреты, API proxy и scheduler. Проверить настоящий Telegram WebView на iOS/Android, OIDC callback, Storage, Stars payment/refund, доставку бота, восстановление backup и требования к нагрузке. Браузерная эмуляция и локальный PostgreSQL не подтверждают работу этих внешних систем.

Ключи, пользовательские выгрузки и Git в клиентский пакет не входят. Минификация frontend не запрещает воспроизведение внешнего вида; значимая технология остаётся на сервере владельца.

## Визуальная доработка — 18 октября 2026

Референс: основной интерфейс OG CRE8R². Главная перестроена вокруг прогресса, бонуса дня и контента; участник получает мобильную композицию до 480px и на компьютере. Убраны декоративные рекламные подписи и повторяющиеся звёзды; появились предметные значки, короткие тексты и анимации действий. Административные экраны сохраняют широкую область. Светлая/тёмная палитры, шрифты и оформление управляются бренд-пакетом.

Подтверждено в этом цикле:

- Финальные production-сборки мастера и самостоятельной копии OG прошли. Runtime-импортов из мастер-папки в OG нет; карты исходников мастера не публикуются.
- 81/81 автоматическая проверка, включая четыре новых проверки геометрии колеса и уникальной площади стирания.
- 5/5 игровых сценариев с сохранением результата: колесо на 320/390/430px, скретч, шесть пар, реакция с ранним нажатием и аркада. `test-results/games-report.json`.
- 5/5 проверок касаний: полная анимация/WebGL, открытие истории, свайп, клавиатура и навигация. `test-results/touch-report.json`.
- 4/4 проверки конфигурации выключенных модулей. `test-results/modules-report.json`.
- В общем сценарии прошли первые 8 проверок: главная, бонус с перезагрузкой, QR-купон, публикация и комментарий, квиз, QR-билет, заказ, бриф. Исправлена потеря нажатия отправки комментария при закрытии клавиатуры.

Общий прогон остановился на холодной загрузке редактора. Для менеджеров добавлена предварительная загрузка административного модуля из профиля; её повторная браузерная проверка, обновлённый CRUD редактора, переключение Team/Academy и проверка тем на desktop остаются неподтверждёнными в этом цикле. Повторное открытие локальной страницы инструмент браузера отклонил по своей политике доступа; обход ограничений не выполнялся. Результаты базовой приёмки выше не подменяют повторную проверку после редизайна.
