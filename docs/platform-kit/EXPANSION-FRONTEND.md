# Проверки интерфейсов — 18 октября 2026

Реализованы интерфейсы подарков и распаковки, паспорта, кабинета и редактора проектов, итогов и пяти отраслей. Карта участника имеет блик и наклон с очисткой сенсора при уходе; раскрытие материала переносит его обложку в подробный экран. При уменьшенном движении декоративные перемещения отключены. Ленту подарка можно потянуть либо активировать кнопкой; купон выдаётся только после ответа API.

## Граница проверки

Браузер работает с явно обозначенным демо; это не реальная оплата или отправка заявки автору. SQL проверен локально через PGlite. Новые гонки возврата воспроизведены последовательностью транзакционных состояний; это не отдельный многопроцессный нагрузочный прогон PostgreSQL. Физические сенсоры, настоящие файлы Supabase Storage, Telegram Stars и доставка облачных webhook требуют проверки в отдельном тестовом окружении. Облачные миграции и публикация не выполнялись.
