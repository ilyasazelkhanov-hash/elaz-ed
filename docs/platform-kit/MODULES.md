# Выбрать модули

Единственный программный реестр — `src/platform/config.ts`. Таблица описывает назначение; наличие интерфейса не заменяет проверку production-сценария.

| ID | Назначение | Автоматические зависимости | Основные роли |
|---|---|---|---|
| content | Статьи, истории, видео, файлы | — | editor |
| learning | Курсы, уроки, задания | content, progress | mentor, editor |
| campaigns | Кампании, миссии, игровые активности | progress | campaign_manager |
| progress | Уровень, достижения, прогресс | — | member |
| loyalty | Баллы, награды, купоны | progress | cashier, campaign_manager |
| commerce | Товары, услуги, заказы | — | editor, cashier |
| events | События, слоты, записи | — | campaign_manager, cashier |
| community | Публикации, комментарии, модерация | — | moderator |
| team | Команды, опросы, программы | community, learning → content, progress | admin |
| retention | Согласие на уведомления, очередь | — | campaign_manager |
| analytics | Показатели и выгрузки доступных данных | — | analyst |

`owner` и `admin` управляют установкой в пределах серверных правил. Роль не даёт неявного права обходить выключенные возможности. Полная матрица фактических action-проверок находится в серверном коде.

## Пресеты

- `club`: главная, активности, привилегии, сообщество, профиль.
- `team`: главная, команда, активности, сообщество, профиль; доступ сотрудников.
- `academy`: главная, обучение, активности, сообщество, профиль.
- `services`: главная, каталог, встречи, сообщество, профиль.

Пресет задаёт стартовую композицию. Флаг `--modules` обязателен: окончательный набор выбирается явно. Например, `learning` добавляет `content,progress`, а `team` — также `community,learning,content,progress`. Если модуль отсутствует, соответствующие пункты навигации и блоки главной удаляются; `home` и `profile` сохраняются. Максимум пять пунктов нижнего меню.

Общий код всех модулей остаётся в клиентском проекте. Отключённые модули должны быть недоступны на сервере, даже если пользователь вручную отправляет action. При изменении состава обновите серверный `az_settings`, а не только JSON/интерфейс, и проверьте отказ соответствующего API.
