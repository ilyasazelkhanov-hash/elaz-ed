# Демовидео убраны

28 октября 2026 по просьбе владельца пять ранее созданных роликов удалены из публичной сборки, галереи и уроков. Прежние сценарии в этой папке — история разработки, а не учебные видео.

Материалы всех 28 программ находятся в основном разделе «Курсы» (`/#/courses`). Академия (`/#/academy`) — отдельное демо вводного модуля. Иллюстрации, скриншоты и практические файлы сохранены в уроках.
