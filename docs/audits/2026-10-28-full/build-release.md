## Подтверждённое замечание

### REL-1 · P2 · Vercel выпускает frontend без регрессионных проверок

**Код:** `vercel.json:4`, `package.json:8`, `package.json:9`–`24`; в отслеживаемом репозитории нет `.github/workflows/`.

**Сценарий:** коммит проходит TypeScript/Vite, но нарушает серверную оплату, API-авторизацию или SQL-права. Vercel выполняет только `npm run build`; эта команда генерирует учебные ресурсы, проверяет TypeScript в `src` и собирает frontend. Ни одна из существующих API/SQL/content/experience проверок не является условием этого выпуска. `tsconfig.json:18` ограничивает проверяемый TypeScript папкой `src`; Edge Function компиляцией frontend также не проверяется.

**Последствие:** реальная регрессия backend/content может попасть в ветку frontend-релиза, несмотря на богатый набор локальных проверок. Это подтверждённый пробел проверки выпуска, а не утверждение, что текущая сборка сломана.

**Исправление:** добавить обязательный CI-check на PR/ветку с Node 24, `npm ci`, build, API/Academy/SQL/experience/news тестами и отдельным `deno check`/проверкой Edge Function; настроить branch protection на этот check. Сам deploy не должен автоматически отправлять сообщения или выполнять финансовые операции.

## Блокер подтверждения рабочей версии

Новая бесконечная лента требует маршрута `blog_feed` в `supabase/functions/api/index.ts`, а Vercel собирает только `dist`. Серверный выпуск отделён от frontend. `docs/fixes/2026-10-28-blog-feed.md` прямо фиксирует, что Edge Function не развёрнута из-за отсутствия безопасно настроенного `SUPABASE_ACCESS_TOKEN`.

При старом API запрос новой ленты вернёт 404; клиент сохранит начальную порцию публикаций и покажет ошибку подгрузки, но полного архива не будет. Источник и обработка сценария подтверждены кодом; текущий ответ рабочего сервера не проверен. Запрос `HEAD https://elaz-ed.vercel.app` отклонён сетевым прокси: `CONNECT 403`. Нельзя делать вывод, что это HTTP 403 самого продукта, и нельзя выдавать push в main за подтверждение выкладки Supabase.

Для выпуска нужны отдельно обновлённая Edge Function, frontend и smoke-test с обычным подписанным Telegram-пользователем. Данные о состоянии рабочей БД и версии миграций из этой среды недоступны.
