# Недельная цель обучения

Функция работает только в основном OG. В профиле пользователь задаёт цель 1, 3, 5 или 7 завершённых уроков, день и локальное время напоминания. По умолчанию — 3 урока, воскресенье, 18:00. Напоминания выключены до явного включения и разрешения Telegram.

Учитываются завершённые уроки из серверной таблицы `progress` с начала недели (понедельник, локальное время пользователя). Если цель уже достигнута или нет доступного незавершённого урока, сообщение не отправляется. Успешная доставка фиксируется максимум один раз за локальную неделю. Ошибки `400/403` отключают напоминания; временные ошибки можно повторить в последующих часовых запусках в выбранный день.

## Публикация

1. Применить `supabase/migrations/20261101100000_learning_goal_reminders.sql`.
2. Развернуть обновлённую функцию `api`.
3. Убедиться, что в Supabase Vault уже настроен `og_api_url`, а в `settings.cron_key` задан существующий секрет.
4. Один раз выполнить `scripts/learning-reminders-schedule.sql` в SQL Editor Supabase. Он создаёт hourly job `og-learning-reminders`; повторное выполнение заменяет предыдущий job с тем же именем.
5. Проверить доставку на тестовом пользователе с включённым Telegram-разрешением; проверить, что без opt-in сообщение не уходит.

Секреты не передаются в URL и не добавляются в репозиторий. Для остановки расписания используйте SQL-команду-комментарий внизу schedule-файла.
