# Карточка участника в профиле

## Причина

Голографическая карточка не была удалена. В `c627ee4b0273bedf44041d75906e6e7d7f8aea91`
от 11 ноября она переехала внутрь закрытого по умолчанию `<details>`
«Уровни и достижения». На `main` `750a081` карточка оставалась там,
ниже библиотеки и настроек.

## Изменение

- `src/screens/Profile.tsx`: одна карточка сразу под заголовком профиля,
  перед обучением. Уровни, достижения и дополнительные разделы остаются свёрнутыми.
- Сохранены голографическая плёнка, блёстки, наклон, имя, аватар, номер,
  текущий уровень, XP и открытие существующего окна «Поделиться».
  Данные берутся из `me`, новый источник данных и доступы не добавляются.
- Декоративные слои не принимают указатель и скрыты от скринридера.
  Имя и нижняя строка могут переноситься, кнопка может расти при увеличении текста.
- При `prefers-reduced-motion` карточка не наклоняется, XP не прокручиваются,
  кнопка не сжимается при нажатии. Статичный блеск остаётся.

## Проверка

`npm run test:profile` проверяет видимое положение вне `<details>`, отсутствие
дубликатов, актуальные данные при смене аккаунта, повторное открытие sharing,
reduced-motion и неизменность доступа к админке.

`npm run test:app-navigation` защищает порядок карточки, обучения и дополнительных
разделов. `npm run test:all` проверяет регрессии и сборку в изолированной копии.

Для проверки на устройстве: открыть профиль, увидеть карточку без раскрытия
блоков; проверить длинное имя и увеличенный текст; открыть и закрыть «Поделиться»;
включить уменьшение движения и убедиться, что декоративный наклон отключён.
Эти автоматические проверки не заменяют визуальную проверку на телефоне.
