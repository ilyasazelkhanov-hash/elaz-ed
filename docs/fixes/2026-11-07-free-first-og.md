# OG CRE8R: бесплатная польза, обновления и платное обучение

7 ноября 2026. Продуктовое направление: в первую очередь место, где новичок находит понятную и бесплатную информацию об ИИ, следит за обновлениями и сохраняет полезное. Отдельные платные курсы — следующий шаг для системного обучения и проекта.

## Что сделано

- Перестроена главная: позиционирование и бесплатный старт, новые публикации, темы и сохранённое, затем платные программы. Игровой бонус сохранён ниже основных материалов.
- В постоянной навигации четыре подписанных раздела: «Главная / Обновления / Курсы / Профиль». Рейтинг остаётся доступным из профиля.
- Пять новых самостоятельных бесплатных разборов: первый запрос, проверка ответа, выбор типа инструмента, бриф обложки, библиотека своих запросов. Есть копирование запроса, примеры, задания и словарь. Бесплатные разборы не копируют платные книги.
- В обновлениях — поиск, темы, непрочитанные и сохранённые публикации, ручное обновление. Личные темы и закладки привязаны к аккаунту в текущем браузере; при заблокированном Storage работают в памяти до закрытия страницы.
- В коде API реализована хронологическая выдача: старое продвижение не вытесняет свежий материал. Применение в production требует проверки. Старый редакционный порядок API сохранён для совместимости. На главной актуальная первая страница запрашивается отдельно от начальной загрузки.
- У пяти курсов разные SVG-превью результата: бриф, документ, видеотаймлайн, экран приложения и процесс. Видны программа, результат, длительность, актуальные условия и бесплатный пробный урок. Цена не подставляется из публичных учебных исходников.
- Убрано чтение полных платных уроков из статического JSON в клиенте. Опубликованные идентификаторы приходят из проверенной серверной квитанции импорта; тело урока — через защищённый API. При отсутствии курса интерфейс сообщает, что продажи не открыты.
- Используется существующий checkout Telegram Stars с серверным подтверждением доступа. В демо пять изолированных синтетических программ с короткими примерами; условная покупка не списывает звёзды и не включает настоящие платные тексты.
- Читатель стал компактнее, навигация по разделам закреплена. В самопроверке сначала собственный ответ, разбор раскрывается отдельно. Черновик и выбранный раздел восстанавливаются для конкретного аккаунта и урока. Копирование кода получило подпись языка и большую область нажатия.
- Исправлены цветовые пары основных действий в тёмной теме, текст успешных состояний в светлой и видимый фокус поиска. SVG-движение останавливается вне экрана и при reduced motion.

## Загрузка

Полные OG-книги исключены из клиентского графа импортов; отдельные экраны Academy подключаются лениво. Модуль Courses уменьшился с 776.71 kB / 147.23 kB gzip до примерно 66.58 kB / 19.49 kB gzip. Это размеры файлов сборки, а не замер скорости сети Telegram. Другие публичные книги Academy с нулевой ценой остаются в своём отдельном контуре.

## Проверка

- `npm run test:discovery` — бесплатный материал, новые/непрочитанные, закладки, темы, цвета, читатель, идентификация курсов и границы доступа.
- `npm run test:api` — подписанные запросы, права, публикации, пагинация, пробные/платные уроки, счета, оплата и возвраты. Добавлены проверки серверной квитанции и хронологической выдачи при большом числе старых закреплений.
- `npm run test:og-practice` и проверки knowledge/experience/content-navigation/main-courses/academy-main-app/course-materials — совместимость материала и прежних маршрутов.
- TypeScript, Vite build и prerender.
- `scripts/og-discovery-browser.cjs` — бесплатная главная, пять разборов, сохранение после перезагрузки, прочитанное, интересы/поиск, пять платных предложений, пробный урок, скрытый разбор ответа, закрытый урок и синтетическая покупка. Светлая/тёмная темы, ширины 320/390 px. Внешние запросы блокируются; реальные платежи не используются. Отчёт и снимки — `test-results/og-discovery`.

Для браузерной проверки нужны запущенный локальный Vite и Playwright. При необходимости укажите `PLAYWRIGHT_MODULE` (каталог установленного пакета), `PLAYWRIGHT_CHROMIUM_EXECUTABLE` и `OG_DISCOVERY_URL`.

Итог на текущих изменениях: 105/105 серверных проверок, 56/56 остальных целевых проверок, TypeScript, сборка и prerender прошли. Все семь групп браузерного сценария прошли; ошибок страницы и запросов к рабочему API не было. Отдельно проверено отсутствие авторского платного упражнения в публичном JavaScript сборки. Просмотрены снимки светлой и тёмной главной, каталога, бесплатного и платного читателя.

Для полного согласованного выпуска нужно проверить API: `practice_key` и опубликованное оглавление по существующей квитанции `content_revision:ai-practice-paths-2026-11-01-v5`, а также порядок `newest` для ленты. Новая миграция для этих изменений не требуется. Совместимость с прежним API сопоставляет программу только по точному уникальному названию; она не выдаёт доступ к урокам.

Уведомления и обещания регулярности публикаций не добавлялись: интерфейс показывает только реально опубликованные материалы и их даты. На настоящем Telegram iOS/Android и с реальной оплатой отдельный выпускной прогон не выполнялся.
