# Навигация, масштабирование и порядок разделов

## Что изменено

- `src/lib/app-navigation.ts` стал единственным владельцем browser history. Пользовательские переходы добавляют запись; нормализация прямого входа и legacy-редирект заменяют текущую. Back, Forward и смена hash обновляют tab и overlay stack вместе.
- Courses, Academy и Post больше не переписывают URL при монтировании или размонтировании. Вложенные учебные экраны получают маршрут из store. Прямой вход без предыдущей записи безопасно возвращается к родительскому экрану.
- История хранит только непрозрачный идентификатор. Черновики редактора и данные пользователя не сериализуются в history.state. При перезагрузке восстанавливается публичный маршрут, а не старое окно редактора.
- Убраны `maximum-scale=1` и `user-scalable=no` из viewport.
- На главной новости находятся перед бонусами и адвентом. В профиле сначала обучение, доступы, библиотека и настройки; карточка, статистика и рейтинг объединены с достижениями. Демо Академии, бизнес и лаборатория находятся в раскрываемом «Дополнительно».

## Проверки

- `npm run test:app-navigation`: переходы главная/профиль, каталог/курс/урок, Back/Forward, смена hash, прямой вход, неизвестный маршрут, закрытие вложенного окна, быстрый Back и более новый переход, legacy-редирект, очистка обработчиков и viewport.
- `npm run test:experience`, `npm run test:profile`, `npm run test:legacy-course`: существующие проверки reader/profile/legacy с обновлёнными harness для единого владельца истории.
- `npm run test:all` выполняет изолированные проверки и сборку, не меняя исходные учебные материалы.
- `scripts/app-navigation-browser.cjs` предназначен для живого Chromium против локального Vite. Настройки совместимы с остальными browser scripts: `PLAYWRIGHT_MODULE`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE`, `UI_ORIGIN`. Скрипт не отправляет внешние запросы и не выполняет покупки. Проверяет реальные клики, Back/Forward, hash/reload, клавиатуру, ширины 320/360/390 и 200% pinch zoom; сохраняет снимки в `test-results/app-navigation-ui`.

## Ограничения проверки в рабочей среде

Запуск Chromium в текущем контейнере завершился до открытия страницы: `socket() failed: Operation not permitted` в ProcessSingleton. Повтор с разрешённым расширением sandbox не устранил системное ограничение. Поэтому живые браузерные проверки, снимки нового интерфейса, физические iOS/Android Telegram WebView, screen reader и фактический 200% zoom не подтверждены. Наличие тестового скрипта не означает, что эти проверки прошли. Перед релизом выполнить его в среде с доступным браузером и проверить системную кнопку Back в Telegram отдельно.
