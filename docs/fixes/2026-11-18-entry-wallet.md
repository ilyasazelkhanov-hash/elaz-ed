## Что изменено

1. Внешний экран OG переносит поддерживаемый публичный адрес в ссылку Telegram и демо. Используется существующий bot `/start` → кнопка `?sp=`; новый frontend восстанавливает маршрут только после обычной авторизации. Публичный allowlist охватывает публикации, каталоги, известные бесплатные разборы, 33 практических урока и известные программы Academy. Payload ограничен 64 символами. Приватные/административные маршруты, произвольные query и referral не переносятся; неизвестное открывает общий вход. Hash имеет приоритет и обновляет ссылки при Back/Forward. Новых backend маршрутов и разрешений нет.
2. В мастере и независимой копии OG купоны разделены на «Доступные» и «История». redeemed и expired имеют разные подписи; прошедшая дата issued также переносит его в историю. Неизвестный статус/невалидная дата не выдаются за доступность. QR существует только у действующего купона текущего участника; при истечении срока и возврате в вкладку экран пересчитывается. Профиль использует тот же критерий. Это отображение по клиентским часам, не замена серверной проверки погашения.
3. Число штампов берётся из `progression.stampsPerReward`: положительный safe integer, legacy/runtime fallback 6. На точной границе цикл визуально полон; следующий визит начинает новый. Более 24 отметок отображаются индикатором. Завершённый цикл не объявляется выданным подарком. Никаких начислений/мутаций наград эти изменения не выполняют.

## Совместимость и перенос

- Изменения фронтенда, без миграций, Edge API deployment или изменения данных.
- Мастер остаётся самостоятельным. В `src/platform-kit` перенесён только scoped diff после сравнения baseline. Полная `sync-og` показала прежние конфликты и не применялась; app/brand/content и SHA-база синхронизации не перезаписывались. Для Modules/Profile/CSS исходное различие с мастером было только типографическим дефисом. В config сохранены остальные отличия, изменена лишь проверка stampsPerReward.
- Генератор новых клиентов получает реализацию мастера. Уже развёрнутые отдельные клиенты автоматически не обновлены.
