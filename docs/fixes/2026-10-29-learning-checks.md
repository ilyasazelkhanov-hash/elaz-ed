# Обучение: все проверки урока

Рабочая копия сверена с origin/main (8cc1136), удалённых изменений не было.

Исправлен C3 из полного аудита: сервер сохраняет прежнее поле assessment для совместимости и дополнительно возвращает весь упорядоченный список опубликованных проверок урока. Для каждой проверки возвращается безопасная сводка и результат пройденного квиза текущей версии. Вопросы, ответы и ключи оценивания в список не включаются.

В уроке с несколькими проверками доступны все квизы и отдельные формы практики. Завершение выполняется отдельной кнопкой после проверок и подтверждается сервером. Пройденный первый квиз не скрывает второй. Формы имеют независимые labels/ID и показывают работы своего assessment. Обычный урок с одной проверкой сохраняет прежний сценарий. Демо поддерживает тот же массив; чтение открытых книг не выдаётся за зачёт.

Проверки: production build, 200 Academy-тестов, отдельное воспроизведение на PGlite с миграциями. `npm run test:multiple-assessments` проверяет два опубликованных квиза, отсутствие ключей в ответе, запрет зачёта после одного квиза, зачёт и сохранение прогресса после обоих.

Для рабочего обучения нужна миграция `20261029090000_academy_multiple_checks.sql` после имеющихся миграций. Она меняет существующую aa_base_action с проверкой ожидаемого определения, не переносит данные и не меняет правила зачёта. Автоматическое применение к рабочей Supabase не выполнено: доступа для выкладки нет. Также остаётся необходимым выпуск Edge Function и учебных пакетов из предыдущих изменений; получение всех материалов и зачёта реальным Telegram-пользователем не подтверждено. Незакрытые платежные, безопасностные и интерфейсные замечания полного аудита этим исправлением не закрываются.
