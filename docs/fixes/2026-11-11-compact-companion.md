# Компактный OG-спутник на главной

Вместо большого блока «Понятно об ИИ. Полезно тебе» главная показывает небольшого фирменного персонажа и одно полезное действие. Шапка OG CRE8R² теперь содержит главный заголовок страницы. Новости и остальной порядок главной не меняются.

## Поведение

- Бесплатный старт: «Меньше „потом“. Больше „умею“» → существующий маршрут `/start`.
- Публикация: «Лови идею. Не только лайк» → конкретная опубликованная статья. Выбирается самая новая непрочитанная из доступной ленты, затем самая новая. Закрытые уроки, истории, скрытые и будущие публикации исключены.
- Адвент: «Тук-тук. Там что-то для тебя» → существующий календарь. Подсказка появляется только в активный день, когда сегодняшняя дверь ещё не открыта. Никакого обещания приза или автоматического получения награды.
- «Другая идея» переключает доступные подсказки. Автоматически текст меняется не чаще одного раза в 14 секунд и максимум дважды за сессию вкладки. Любое ручное взаимодействие останавливает автосмену.
- Пауза выключает движение и автоматические подсказки. Сворачивание оставляет одну компактную строку. Оба выбора сохраняются в сессии отдельно для каждого аккаунта; при недоступном хранилище работает память страницы.

Это подготовленные навигационные фразы, не чат и не модель ИИ. Компонент не делает сетевых запросов, не добавляет зависимости, не отправляет уведомления и не начисляет XP. Персонаж нарисован CSS: парение, моргание, мягкая тень и небольшая звезда, без видео, Canvas или WebGL.

## Доступность

- `prefers-reduced-motion` полностью убирает анимацию и автосмену.
- Движение и таймер останавливаются вне видимой области, в скрытой вкладке, под открытым экраном, при наведении и клавиатурном фокусе.
- Кнопки минимум 44 × 44 CSS px, видимый фокус, содержательные доступные названия.
- Сворачивание сохраняет кнопку в DOM, с `aria-expanded` и `aria-controls`.
- Автоматические фразы не озвучиваются. Результат явного нажатия «Другая идея» объявляется через отдельный status.
- Компонент остаётся в потоке документа и не закрывает контент или навигацию. Светлая и тёмная темы используют существующие контрастные цвета.

## Проверки

- `npm run test:companion`: 9 тестов, выбор реальных действий, состояния адвента, хранение настроек, SSR-разметка, reduced-motion.
- `npm run test:discovery`: 33 теста.
- `npm run test:app-navigation`: 10 тестов.
- TypeScript: без ошибок.
- `npm run test:all`: первоначальный прогон 35 из 36 этапов; все этапы сборки прошли. Единственная ошибка существующего `progress-awards.test.mjs` воспроизведена на неизменённом интеграционном HEAD: SQL `current_date` использует UTC+5, а фикстура RPC — дату UTC JavaScript. Ошибка не относится к спутнику. Повторный `TZ=UTC npm run test:all` прошёл все 36 этапов. После финальной правки остановки автосмены на взаимодействие повторно прошли 9 тестов спутника, TypeScript и Vite build.

Подготовлен `scripts/home-companion-browser.cjs` для локальных проверок 320/360/390/768 px, двух тем, размеров кнопок, действий, возврата, клавиатуры, сворачивания и ограниченной автосмены. Также обновлены старые smoke-проверки удалённого hero.

**Визуальная проверка не завершена в текущей среде:** локальный Chromium не запускается из-за ограничения socket(), в том числе после запроса разрешённого расширенного запуска; встроенный браузер не видит локальный сервер. Скрипт синтаксически проверен, но его прохождение и фактические размеры компонента не подтверждены. До публикации нужно выполнить browser smoke и посмотреть мобильный/десктопный вид и масштаб 200% в доступной браузерной среде.
