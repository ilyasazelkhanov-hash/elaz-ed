# Новости на главной и регулярные подборки

7 ноября 2026. Запрос: отделить новости от материала курсов, добавить фильтры на главную, выпускать несколько новостей каждые три дня с изображениями, назвать вкладку «Новости».

## Что изменено

- Вкладка и связанные пользовательские подписи называются «Новости». Внутренний маршрут `blog` и прежние ссылки сохранены.
- На главной работают поиск, темы, категории и режимы «Новые / Непрочитанные / Сохранённые», сброс и понятные пустые состояния. Сначала показаны три подходящие карточки; можно раскрыть больше, загрузить следующую страницу или перейти ко всем результатам с выбранным фильтром. Счётчик относится к загруженной выборке.
- Главная и раздел новостей используют один механизм загрузки. При отсутствии `blog_feed` только конкретный ответ `404/not_found` включает совместимость со свежим authenticated `boot` без параметров приглашения. Запреты доступа и ошибки сети не маскируются. Ограниченная старая выдача не называется полным архивом.
- Сохранён порядок главной: вводный блок → стрик/бонус → адвент → новости → темы → курсы.

## Разделение материала

[Аудит происхождения](../audits/2026-11-07-news-course-overlap.md) подтвердил, что статьи 159–166 созданы из тех же авторских упражнений, что и курсы. Остальные 122 самостоятельных публикации не исключались по одному совпадению темы.

В рабочем проекте `dcdepwdxvadhludnubis` применена только добавочная миграция `20261107104626_news_course_boundaries.sql`. Перед применением хеши восьми текстов сверены с исходниками; оригиналы и определения функций/представления сохранены в игнорируемом приватном каталоге.

У восьми записей установлен `news_eligible=false`. Представление `feed_cards` и существующая очередь доставки исключают их из новостей. Статьи остаются опубликованными для прежних прямых ссылок; их тела, идентификаторы, привязки и прогресс не удалены. Подтверждено сохранение 50 опубликованных курсовых уроков и общего количества записей прогресса.

Генератор и импорт справочных упражнений сохраняют этот признак при повторном запуске. Триггер также исключает известные тела упражнений и курсовые записи из новостного назначения. Для новых редакционных публикаций подготовлена серверная проверка пересечения с курсовыми текстами; полный новый API этим выпуском не развёртывался.

## Автоматизация и первая подборка

Создана активная автоматизация Codex `og-cre8r` в текущем чате: каждые три дня в 10:00 по местному часовому поясу Asia/Qyzylorda. Она ищет свежие первоисточники, готовит несколько самостоятельных русскоязычных новостей и запускает проверку и пакетную публикацию. Ориентир 3–5 новостей, больше при наличии полезных событий; строгой квоты на одну новость нет. Для выполнения нужен доступный локальный хост Codex и действующая авторизация CLI.

Публикатор:

- Требует источник, дату события, дату проверки, ограничения и обязательную релевантную обложку.
- Проверяет публичный HTTPS-адрес изображения, DNS/переадресации, размер и реальный формат JPEG/PNG/WebP. Изображения проверяются и при пробном запуске.
- Сравнивает текст с действующими курсами и 47 версиями авторского комплекта; дубликаты, существенные заимствования и устаревшие/будущие события отклоняются.
- Записывает всю подборку и квитанции атомарно. Периодичность относится к подборке. Повтор идентичного пакета возвращает прежние ID.
- Не меняет курсы, доступы, цены и расписание канала; не отправляет сообщения напрямую. Уже действующая очередь отвечает за доставку новых публикаций.

В рабочей базе опубликованы четыре новости, ID 183–186: Google Vids, прототип по рисунку в Gemini, Guided Learning и исследование применения Claude в науке. Каждая получила проверенную официальную обложку первоисточника. Повторная проверка с изображениями вернула те же четыре ID и пустой `inserted_ids`, без новых дублей. Исходный открытый пакет: [первая подборка](../../content/news/2026-11-07.json).

Обложки добавлены в приложение. Обновление изображений в четырёх уже отправленных Telegram-сообщениях отдельно не выполнено: автоматическая проверка разрешений отклонила извлечение `cron_key` и изменение сообщений через production worker без дополнительного явного согласия на этот способ. Повторные сообщения не отправлялись.

Порядок следующих выпусков: [NEWS-AUTOMATION](../NEWS-AUTOMATION.md).

## Проверки

Проверены SQL-границы ленты/очереди, сохранность прямых ссылок и прогресса, фильтры, совместимость старого API, пакетная атомарность/откат, периодичность, повторный запуск и изображения. TypeScript и граф Edge API проходят проверку. В браузере прошли восемь групп, включая настоящие взаимодействия с фильтрами главной, название «Новости» и мобильные размеры в обеих темах; ошибок страницы и обращений к рабочему API в демопрогоне нет.
