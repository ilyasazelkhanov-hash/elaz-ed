# Практика с собственным результатом

## Зачем

Из исследования Coursiv взят принцип маленького законченного действия, а не копирование воронки или оценок. В бесплатных разборах уже были задания и критерии, но результат некуда было записать. Теперь ученик может сохранить результат, способ проверки и исправления.

## Область

- `FreeStart`: реальные критерии текущего бесплатного разбора вместо дублирующего статического списка.
- `PracticeReader`: работа во вкладке практики; переходы между разделами не размонтируют редактор.
- Новый `PracticeArtifact` не заменяет Academy submissions, рубрики преподавателя или портфолио. Не начисляет XP, не отмечает серверное завершение и не выдаёт сертификат.

## Честные состояния

Пусто → черновик → самопроверка выполнена. Последнее означает только заполненные поля и отмеченные самим пользователем критерии, не качество работы и не подтверждённый навык. Feedback детерминированный: показывает отсутствующие поля и неотмеченные критерии; текст не оценивается ИИ.

При редактировании поля чекбоксы сбрасываются. Смена версии критериев сбрасывает сохранённую самооценку, но не удаляет текст.

## Данные

По умолчанию текст только в памяти компонента. Локальное сохранение исключительно по кнопке, отдельно для аккаунта, demo/live, курса и урока. Без синхронизации и серверной отправки. Гостю доступен экспорт .txt. При ошибке storage не показывается успех. Удаление с явным подтверждением относится только к этой локальной работе; скачанный файл не удаляется. Ввод ограничен 12 000 символами на поле. Не вводить пароли, данные пациентов и необезличенные личные данные.

Перед уходом на другую страницу необходимо сохранить или скачать работу. Предупреждение browser beforeunload является best-effort, WebView может его не показывать. SPA-переход без сохранения не синхронизирует текст и не должен описываться как автосохранение.

## Проверки

- Unit: namespace isolation, blocked/corrupt storage, rubric revision, feedback, export disclaimers, local deletion.
- SSR: реальные поля, критерии, privacy disclosures, no external calls, existing readers.
- TypeScript.
- Требуется integrated browser QA: 320/390 px, поле/сохранить/перезайти, смена раздела, отмена удаления, export в Telegram WebView, длинный текст и обе темы.
