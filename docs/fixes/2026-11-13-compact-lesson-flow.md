# Компактный урок OG: идея → попытка → разбор → своя работа

Baseline: `9389a19b497e924899bfe2f9a29aac0ca5a0d74c`. Это frontend-пакет, не перенос Academy, не новая проверка знаний и не публикация контента в БД.

## Что исправлено

Раньше verified-тренировка стояла под полным Markdown урока. Концепт, вопрос, обратная связь, проверка и переход конкурировали на одном длинном экране. В первом уроке foundations перед тренировкой находилось 5 556 символов исходного объяснения.

- `GuideJourney` теперь показывает один этап: короткую идею, затем отдельный вопрос, затем объяснение результата. Основная кнопка ровно одна: «К вопросу» / «Проверить ответ» / «Попробовать ещё» / «Дальше». Правильный вариант не переводит автоматически на следующий экран.
- При ошибке показаны объяснение и повтор. Повтор сохраняет ответ. Редактирование даже ранее правильного ответа снимает результат проверки, пока пользователь не проверит новый вариант.
- Числа, выбор и перестановка остаются настоящими существующими заданиями. Перетаскивание не требуется; используются подписанные кнопки. Прогресс обозначает место в уроке, а не освоение навыка.
- Reviewed OG flow начинается с короткой идеи. Исходное объяснение остаётся доступно через «Исходный материал урока», «Читать» и «Весь урок». Это не подмена авторского содержания кратким пересказом.
- Для unknown/mismatch/pending/no-crypto остаётся обычный Reader без добавленного упражнения. Его исходное объяснение делится на короткие фрагменты около 600 символов. Объединение фрагментов побайтно воспроизводит переданный текст. Fences, таблицы, списки с продолжениями и заголовок с первым абзацем не разрываются. Крупный атомарный блок остаётся целым и прокручиваемым. Документы с reference definitions читаются целиком, чтобы не потерять область разрешения ссылок.
- Header короче, вторичное описание результата раскрывается по запросу. Отметка ознакомления, отдельная проверка и условия доступа находятся в явном раскрываемом разделе «Отметки и доступ к курсу». Их кнопки и исходные условия не удалены, платежные действия не менялись.
- PracticeArtifact остаётся смонтированным при смене секции. Есть прямой доступ к собственной практике без обязательного прохождения формативного квиза. Черновик и сохранение не смешиваются с отметкой курса.

## Доступность и мобильная система

- Native radio/fieldset, числовое поле с текстовой подсказкой, 44px+ controls, видимый focus, summary с tabIndex.
- Переходы фокусируют текущий заголовок без прокрутки внешнего shell; прокручивается только ближайший штатный `.scroll`. Reader также больше не вызывает `scrollIntoView` всех предков. Вложенная OG-тренировка учитывает 76px sticky-навигации Reader; свободные разборы сохраняют собственный 12px inset.
- Ошибка/успех различаются текстом и значком, не одним цветом. Feedback объявляется `role=status`/polite.
- Новое движение только короткое появление после действия пользователя; при reduced motion отключается. Нет бесконечной анимации, таймеров, звуков или confetti.
- Ширина дочерних блоков ограничена родителем, длинный текст переносится. Малые экраны не получают фиксированной высоты или обрезки содержания. Цвета и типографика используют существующие semantic tokens OG.

## Неизменяемые границы

- Exact reviewed-body SHA-256 guard и его active/body/key protection не изменены. Registry, ключи уроков и API доступа не изменены.
- Нет импорта платных книг в компонент, сетевых запросов, role override, новых XP, certificate или completion вызовов.
- Формат session journey, ключи draft/artifact storage, scoped account/demo isolation и shelf deep links не изменены.
- Исходный registry в baseline содержит 2 reviewed OG flow. Дальнейшее добавление Academy-informed authored content является отдельным пакетом. Наличие локального исходника не доказывает совпадение с опубликованным body и не подтверждает доступ к платному уроку.
- Деление на страницы применяется только к уже разрешённому body. Это интерфейс чтения, не автоматически созданный учебный план и не доказательство качества 33 уроков.

## Основание решения

Принципы Coursiv/Duolingo адаптированы как «одна задача → попытка → понятная обратная связь → следующий шаг», без копирования бренда, кода, подписного funnel или обещаний учебной эффективности. Использован существующий [план адаптации Coursiv](../roadmaps/COURSIV-ADAPTATION.md), пункты C07/C09/C11/C16/C17, и [дизайн-контракт OG](../../DESIGN.md). Платные аккаунты референсных продуктов в этой итерации не исследовались.
