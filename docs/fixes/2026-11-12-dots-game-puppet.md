# Dots: непрерывный игровой rig вместо смены картинок

## Запрос и выбор метода

Пользователь одобрил пушистые формы, но отверг переключение кадров и плоские аксессуары. Поэтому предыдущая реализация `696ee2c` заменена, а не украшена ещё одной CSS-анимацией.

- Frame atlas/crossfade дешёв, но не даёт независимых движений. Больше не используется как основная анимация.
- WebGL/Three даёт полноценное 3D, но был отключён в реальном проверочном браузере. Возвращать геометрию/SVG при этом нельзя.
- Выбран нативный Canvas2D: 2D skeletal puppet с деформируемыми текстурами, артикулированными плечами/локтями, непрерывными числовыми параметрами лица. Это не полноценная вращаемая 3D-модель; глубина изображена материалом, перекрытием частей и skinning.
- В [документации Rive](https://rive.app/docs/editor/manipulating-shapes/meshes) подтверждён сам принцип raster meshes + bones. Rive/Pixi/Spine и новые внешние runtime-зависимости в приложение не добавлены. Лицензируемый сторонний персонаж не используется.

## Арт

Два новых оригинальных атласа созданы встроенным image_gen. Каждый 1536×1024 с настоящей альфой; WebP с сохранённой альфой, вместе около372KiB. Точные размеры и SHA256: `public/companion/provenance.json`.

- `puppet-fur-v2.webp`: три одобренных силуэта в виде чистых меховых туловищ, без нарисованных глаз, лап и стоп; отдельные меховые лапка, ступня и запасная текстура века.
- `puppet-props-v2.webp`: объёмные черепаховые очки, кожаные наушники, ботанический росток, фонарь и глянцевые глаза. Для очков отдельно исправлены отверстия: центры линз действительно alpha0, а не белая заливка.
- Предыдущие полноценные изображения остаются **только статическим резервом** при загрузке/ошибке Canvas. Активный rig никогда не меняет картинку лица или готовую позу.

Основной prompt: preserve original lavender plush forms and short dense fur, matching soft studio light; production 3×2 transparent rig atlas with three faceless limbless torsos, separate capsule arm and oval foot; no scene, no text, no baked shadows. Accessories prompt: tangible miniature material-rich objects, matching camera/light, tortoiseshell rims with fully transparent empty holes, padded leather earcups/headband, botanical leaves; not SVG icons. Полные assets созданы через image_gen, затем только WebP-кодирование. Рабочие пиксели не заменены чужой графикой.

## Движение

`puppet-motion.ts` отделён от renderer и React:

- единое состояние позы и аналитические пружины без очереди старых реакций;
- разное запаздывание взгляда, головы, туловища и аксессуара;
- дыхание/перенос веса, редкие взгляды и плавное закрытие век;
- touch: подготовка, короткий подъём, приветствие лапой и затухание;
- непрерывные smile/open/gaze/eyelid параметры, а не crossfade;
- новая реакция равного/большего приоритета заменяет текущую, не накапливает импульсы;
- dt ограничен, поздний callback после остановки нейтрализован.

`puppet-renderer.ts`:

- 96 треугольников мягкого skinning туловища и 72 треугольника двух лап, всего168;
- нижняя часть тела остаётся опорной, верхняя следует голове;
- лапы гнутся в локте, корни скрыты под туловищем; ступни независимы;
- глаз остаётся одного размера, веко закрывает его через клип; закрытый край дорисовывается тонкой кривой;
- очки привязаны к лицу; дужка наушников за головой, подушки перед ней; у ростка/реквизита своё затухание;
- фонарь висит у лапы, а не вращается вместе с ней как наклейка; границы проверены на полном цикле;
- палитра запекается один раз вне цикла, без зависимости от необязательного Canvas.filter.

## Производительность, доступность и отказы

- Максимум30FPS, не новый React render на каждом кадре. Backing store224×269, менее61тыс. пикселей, не увеличивается на DPR3/4.
- Подготовка изображений отдельно от запуска RAF. При hidden/offscreen/покрытии модалкой, выключенных анимациях и reduced-motion RAF действительно отменяется, не продолжает пустой цикл.
- Не теряется статичная мимика/кастомизация в режиме без движения.
- Все context acquisition / initial paint / static paint / tick failure пути приводят к освобождению painter и статическому fallback. Потеря контекста во время загрузки не может объявить готовность; восстановление создаёт новый renderer.
- Ошибки устаревшей резервной картинки не портят новую форму. Незавершённые image handlers отключаются при cleanup.
- Canvas декоративный `aria-hidden`; настоящие кнопки и доступная реплика находятся вне него. Они не зависят от готовности арт-движка.
- Никаких новых запросов к датчикам, камере, микрофону, аппаратному фонарику. Существующий opt-in движений и явный запуск голоса сохранены.

## Проверки

Unit/SSR проверки включают математическую стабильность пружин, независимость частей, закрытие век, приоритеты/прерывания, остановку RAF, альфу/лимиты assets,48 сочетаний внешности, очистку canvas failure paths и границы фонаря на300 кадрах для каждой формы. Сохранены прежние tests пользовательских данных, честных CTA и sensor consent.

Получены180 последовательных кадров native Canvas и6-секундная запись реальной отрисовки renderer. Проверены формы, посадка реквизита, промежуточные фазы жестов и моргание. Это **не браузерный/mobile benchmark**: измерение CPU через native Canvas в тестовой среде не обещает FPS телефона. Фактические browser QA, CI и live identity проверяются отдельно для опубликованного commit. Физический телефон, аппаратные датчики/голос и системный reduced-motion нельзя считать проверенными по исходникам.
