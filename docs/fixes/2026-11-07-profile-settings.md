# Профиль: настройки, доступность и актуальность

База проверки: `925b3a7802ba461047e6eb2418a3a7147d22d0a7`. Изменения не затрагивают админку, навигацию урока, серверные маршруты и БД.

## Исправлено

- Ошибка загрузки недельной цели больше не оставляет вечную «Загрузку»: есть отдельная ошибка и ручной повтор. Затянувшееся ожидание имеет отдельный статус; таймаут интерфейса не считается отменой серверной записи.
- Цель, день, время, часовой пояс и согласие на напоминания сначала редактируются как черновик. «Сохранить» отправляет один запрос; «Отменить» возвращает подтверждённые настройки. Неуспешная отправка не выглядит успешной.
- Если запись могла дойти до сервера, интерфейс не повторяет её автоматически. После таймаута отмена, чтение и новые правки блокируются, пока исходный promise ещё выполняется. Поздний успешный ответ применяется только в текущем открытии экрана; поздний отказ требует отдельной сверки. Даже после успешного чтения при сетевом отказе остаётся оговорка: сервер мог получить предыдущую запись с задержкой.
- Запрос разрешения Telegram нужен только при включении напоминаний. Отказ не отправляет запись. Повторные нажатия, уход с экрана и поздние ответы из предыдущего открытия покрыты тестами.
- Часовой пояс не меняется незаметно вместе с целью. Он показан явно; пояс устройства можно выбрать отдельной кнопкой. Доступны все допустимые сервером цели: от 1 до 7 уроков.
- Демо не позволяет менять временные настройки, которые его API не сохраняет. Демо-цель подписана как пример, а не реальная статистика. Сброс демо требует подтверждения с перечислением области: исходные уроки/курсы, созданные материалы, прогресс, награды, лайки, доступы, условные покупки/заявки, попытки, окна и коды адвента. Закладки, темы, отдельные демо-разделы и настоящий аккаунт не затрагиваются.
- Настройки подняты выше дополнительных разделов. Длинный список уровней и достижений свёрнут в доступный нативный disclosure.
- У темы и звука есть `aria-pressed`, у формы подписи и статусы; основные цели касания не ниже 44 px. На узких экранах поля расписания и дополнительные ссылки перестраиваются в одну колонку. Полное имя переносится вместо обрезания.
- Диалог достижения использует существующий FocusLayer: фокус ограничен диалогом и возвращается к вызвавшей кнопке, доступен Escape и явная кнопка «Закрыть».
- Карточка профиля уважает reduced motion. Для выделенных кнопок используется контрастная пара `violet / on-violet`.
- Ссылка канала подписана «Канал OG CRE8R» по прямому уточнению владельца; прежний `meta.channel.invite` сохранён. Устаревшее имя из метаданных не подставляется.
- Подпись «Поделиться карточкой» не обещает доступность публикации в сторис на любом устройстве. У библиотеки пояснено локальное хранение закладок и тем.

- После возврата из урока данные цели можно обновить кнопкой «Обновить прогресс». Счётчик подписан «По последней загрузке»; обновление заблокировано, пока есть несохранённый черновик. Полная сверка после неопределённой записи остаётся отдельным действием и предупреждает о замене черновика.

## Что учитывает недельная цель

`learning_goal` и `learning_reminders` в `supabase/functions/api/index.ts` считают завершения текущей недели для пользователя из `progress`, без фильтра по `course_id`. Поэтому в цель входят и OG-курсы, и отдельные уроки ленты: `SecurePracticeLesson` в `OGPractice.tsx` вызывает `api.complete`, серверный `complete_lesson_awarded` вызывает `complete_lesson`, который пишет в `public.progress`. Отдельная Academy пишет в `aa_progress` и в эту метрику не входит. Следующий урок выбирается из доступных незавершённых уроков `feed`. Первоначальное утверждение об исключении OG-курсов было ошибочным и исправлено до интеграции. Запуск production cron и фактическая доставка Telegram-напоминания не проверялись.

Нулевой счётчик непрочитанного относится только к загруженной подборке `updateSummary(feed, read)`, а не ко всему архиву. Карточка в этом состоянии говорит «Посмотреть новости» и не утверждает, что всё прочитано.

- Общий `npm run test:all`: 25 из 25 этапов прошли в изолированной копии (включая content generation, TypeScript, Vite и prerender). Итог общего запуска хранится в `test-results/audit-validation.json` текущего checkout. Vite сообщает о существующих чанках более 500 kB; сборка завершена успешно.
- Browser UI/live проверка не выполнена: локальный Chromium завершается с `socket() failed: Operation not permitted`, CUA не видит локальный Vite (`ERR_CONNECTION_REFUSED`). SSR не является визуальной или end-to-end проверкой. Нужна интерактивная проверка на телефоне/Telegram: светлая и тёмная темы, 320–430 px, сохранение/отказ разрешения, Escape/закрытие достижения, отмена сброса демо.

## Остаётся проверить интерактивно

Переход из диалога достижения в общую карточку «Поделиться» одновременно закрывает исходный диалог. Возврат фокуса после закрытия общего окна в этом вложенном сценарии не подтверждён: сохранённый opener может уже исчезнуть. Без браузерной проверки этот сценарий не рефакторился; обычное закрытие достижения использует существующий FocusLayer.

## Ограничение неопределённой записи

API не возвращает operation ID/версию настройки и не поддерживает подтверждённую отмену. Таймаут интерфейса не доказывает, что запись не дошла до сервера. В текущем смонтированном контроллере исходный promise отслеживается до завершения; пока он ждёт, новая проверка или запись не запускается. После сетевого отказа одно чтение показывает только состояние на момент проверки, а не окончательный исход старой записи. Оговорка об этой неопределённости сохраняется до конца жизни текущего контроллера даже после следующего успешного сохранения: старый запрос теоретически может завершиться позже нового. Таймаут интерфейса без отказа транспорта отличается: поздний успешный ответ того же запроса снимает его собственную неопределённость, но не более раннюю. При полном уходе с экрана или перезагрузке связь с исходным promise теряется; старые callbacks инвалидируются, но серверную запись это не отменяет. Без изменения серверного контракта полная гарантия после перезагрузки невозможна. UI не обещает её.

Контроллер передаёт реальные ошибки чтения/записи в существующий store.guard (в том числе locked), но не выдаёт собственный таймаут или отсутствие ответа на разрешение Telegram за серверный отказ доступа.
