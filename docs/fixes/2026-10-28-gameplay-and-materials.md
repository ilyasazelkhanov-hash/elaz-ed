# OG: геймификация, рейтинг и материалы курсов

Возвращена главная с уровнем, XP, стриком, календарём и ежедневным бонусом. Нижнее меню: **Главная / Рейтинг / Профиль**. Курсы и блог открываются с главной. Блог остаётся отдельным читателем публикаций без квизов и учебных XP. Предыдущий вариант с четырьмя вкладками отменён.

Обложки курсов получили объёмные SVG-иллюстрации с тематическими значками и анимацией. Анимация останавливается вне экрана, в скрытой вкладке и при настройке уменьшенного движения. Исправлено отображение нативного эмодзи при ошибке CDN.

## Настоящий материал внутри курсов

Причина пустоты: frontend содержал программу, а доставка полных текстов зависела от отдельной публикации в серверную базу. Теперь сборка включает 28 отдельных книг: **112 модулей, 448 уроков**. Внутри объяснения, примеры, изображения, практика, самопроверка и ссылки на рабочие файлы. Книга загружается при открытии курса. Виден порядок уроков, есть соседние занятия и переход между модулями.

Публичная редакция строится по явному списку разрешённых полей только для опубликованных бесплатных авторских курсов без привязки к старым платным курсам. Все текущие 28 курсов соответствуют этим условиям. Ключи квизов, серверные задания и рубрики оценивания, сведения об учениках и произвольные служебные поля исключены. Тест проверяет исключение подставленных приватных данных.

Чтение не создаёт зачисление, XP, оценку или фиктивное завершение. Сдача работ и официальный прогресс продолжают использовать защищённый API. Отказы авторизации не подменяются успешным ответом. При недоступном сервере текст доступен, а зачёт явно обозначен как недоступный. Академия остаётся отдельным демо; старые курсы скрыты, демовидео не возвращены.

## Проверки

Сборка TypeScript/Vite прошла. Academy: 198 тестов, API: 83, новости: 14, модели интерфейса: 6 — без ошибок.

`scripts/og-gameplay-browser.cjs` проверяет production-сборку с намеренно отключённым API курсов (503): все 28 книг возвращают 200, в каждой 16 содержательных уроков; чтение, перезагрузка, переход 1.4 → 2.1; отсутствие фиктивных зачислений и оценок. Проверены меню, рейтинг, видимость геймификации, фактическое движение обложки и остановка при reduced motion, отсутствие сломанных эмодзи при отказе CDN. Ширины 320/390/1024, ошибок JavaScript нет. [Результат](og-gameplay/checks.json).

Дополнительно прошли сценарии `og-clarity-browser`, `main-courses-browser`, `audit-fixes-browser`, `academy-study-browser`: блог, редактор публикаций, серверный прогресс, отдельное демо, восстановление ошибок сдачи и работа с уроками.

Управление открытым встроенным браузером пользователя в этой сессии недоступно. Проверка действующего Telegram и выкладки отдельно не подтверждена. Изменение не выполняет реальные оплаты, рассылки или запись в рабочую базу.
