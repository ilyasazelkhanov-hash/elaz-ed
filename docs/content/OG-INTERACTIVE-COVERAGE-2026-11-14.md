# Проверка покрытия интерактивом

## Что является источником

`content/ai-practice-2026-10-25/paths.json` содержит 33 исходных урока пяти направлений. Это авторский источник в репозитории, а не выгрузка текущей production-БД. Исходные body этой правкой не меняются.

Настоящий путь: `SecurePracticeLesson` в `src/screens/home/OGPractice.tsx` находит курс и урок по серверному mapping, проверяет доступ, получает body через `api.lesson`, проверяет id/course_id/kind/published. `PracticeReader` получает этот разрешённый body; `ogLessonInteraction` показывает оригинальный учебный пример только при точном UTF-8 SHA-256 совпадении с рассмотренным источником. SHA проверяет совместимость, а не право доступа.

Примеры в frontend публичны и не являются защищёнными материалами курса. Они не содержат полного текста платных уроков, не заменяют исходник, не изменяют completion, quiz, XP, сертификаты или оплату.

## Как сверить разрешённую контентную выгрузку

Не нужны пользователи, платежи, прогресс, токены или секреты. Нужен только разрешённый владельцем экспорт:

```json
{"lessons":[{"courseKey":"foundations","lessonKey":"block-1","body":"…","published":true}]}
```

```sh
node --experimental-strip-types scripts/og-interaction-coverage.mjs content-export.json
```

Скрипт только читает локальный файл. Он не обращается к сети, не публикует уроки, не исправляет body и не печатает его в отчёт. Статусы: compatible / body_mismatch / not_authored / unpublished. Отдельно перечисляет отсутствующие ключи. Сохраняйте экспорт вне git; удаляйте через обычный согласованный процесс хранения данных.

`compatible` означает совпадение предоставленных байтов, а не факт актуальности или доступности ученику. Для live-подтверждения дополнительно нужны проверенный источник выгрузки, текущие import receipt/API revision и прохождение настоящего учебного сценария. Самопроверка source-файла не может стать доказательством production.

## Границы результата

Три шага и три задания на урок - дополнительный интерактивный разбор, а не законченная переработка всего урока. Практический артефакт ученик делает самостоятельно; правильный ответ в учебном примере не подтверждает профессиональный навык. Нет заявления, что все 33 сценария активны в production.

## Редакторская проверка

Проведена перекрёстная проверка четырёх тематических пакетов. Исправлены: неопределённый timezone; конфликтующие даты в брифах; пропущенные исходные условия для ответов; числовые лимиты отдельного упражнения; сценарий восстановления после частичного сохранения; зависимость порядка операций. Пример FormsKit обозначен как бумажный учебный выбор параметров, а не существующая исполняемая библиотека. При отсутствии реального инструмента результат нельзя заявлять протестированным.

Автотесты сверяют все 33 source hash, отклонение изменённых body, правильные ответы, каждый дистрактор, исходный неверный порядок и семантическую разметку таблиц. Это проверка учебного frontend, не независимая проверка live-данных.
