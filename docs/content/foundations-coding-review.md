## Педагогическая проверка

- block-connections: карта минимальных прав, отличие модели/коннектора/Skill/MCP, проверка чтения и отключения. Новый сценарий с двумя учебными CSV вместо копирования платного текста.
- foundations-skill: процедура карточки занятия, три входа и разные вопросы для отсутствующей аудитории/длительности; версионирование и перенос нового ограничения.
- block-openbot: две роли, отбор checked-строк, реальная доступность файла и отрицательный тест при удалённом факте. Не заявляется фактический запуск приложения.
- foundations-compare: одинаковый вход, обязательные критерии раньше стиля, «не проверено» для отсутствующего измерения, повтор на другой аудитории. Арифметика 416 - 400 = 16.
- coding-spec: observable states, trim, границы 2/24, отрицательные 1/25, локальное подтверждение без сервера. Из шести случаев проходят два.
- block-opencode: одна минимальная правка, план/diff/запуск/регрессия, локальный счётчик; «Алия» после trim = 4 обычные буквы.
- coding-mcp: версия справки, конфигурация против успешного запроса, минимальная правка и фактическая проверка. FormsKit полностью вымышлен, API прямо не предназначен для реального проекта.
- coding-version: локальное состояние/Git/URL, обратимость без удаления новой работы, отдельная проверка публикации.
- block-agent-reach: автономный комплект, новая функция плюс регрессия, чистая копия и повтор README, ограничения локальной формы.

## Ограничения

- Это формативные вопросы: ответы клиентские и не должны заменять оценку практического артефакта или давать платный доступ.
- Нет точных актуальных обещаний интерфейсов, тарифов, лицензий или доступности сервисов. Исходные упоминания версий/названий требуют отдельного свежего аудита; они не повторены как новые факты в примерах.
- Числа и организации в сценариях учебные. Нет пользовательских данных, ключей, сетевой отправки или установки.
- Перед включением: schema/evaluator tests, независимый обзор, точный SHA guard для body, затем доступная live-проверка. Подготовка JSON не означает публикацию.
