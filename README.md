# Elaz Ed

Telegram Mini App для подписчиков канала: уроки, сторис, квизы, XP, стрик, уровни, рейтинг.
Бот — [@elazart_bot](https://t.me/elazart_bot).

## Как устроено

| Часть | Где живёт |
| --- | --- |
| Интерфейс (React + Vite + Tailwind + Motion) | `src/`, хостинг — Vercel |
| API и вебхук бота | `supabase/functions/api/index.ts`, Supabase Edge Function |
| База | Supabase, проект `dcdepwdxvadhludnubis`, схема — `supabase/migrations/` |

Таблицы закрыты RLS без политик: читать и писать может только Edge Function.
Каждый запрос подписан `initData` Telegram, сервер проверяет подпись токеном бота и подписку через `getChatMember`.

## Безопасность

- **Вход.** Сервер принимает только `initData` с верной подписью и не старше 48 часов. Имя, id и права берутся из подписанных данных и из базы, а не из запроса.
- **База.** Ключей Supabase во фронтенде нет: приложение ходит только в Edge Function. Таблицы закрыты RLS, функции базы отозваны у `anon` и `authenticated`.
- **Админка.** Каждый админский запрос проверяется на сервере (`is_admin`), скрытые кнопки в интерфейсе — только удобство.
- **Вебхук.** Telegram присылает секрет в заголовке; без него запрос отклоняется. Адрес вебхука функция берёт из окружения своего проекта.
- **Оплата.** Цена берётся из базы, счёт привязан к покупателю, перед списанием сервер сверяет сумму, валюту и то, что курс ещё не открыт.
- **Браузер.** Заголовки в `vercel.json`: политика безопасности содержимого (скрипты только свои и `telegram.org`, запросы только к своему адресу и Supabase, встраивать приложение может только Telegram), запрет на подмену типа файлов, отключённые камера, микрофон и геолокация.

Что остаётся по построению и не считается дырой:

- Квиз проверяется на сервере, но правильные ответы приходят в приложение вместе с уроком — иначе не показать разбор сразу после ответа. Подсмотреть их в трафике можно; на кону только XP.
- «Сегодня» для бонуса дня считается по часовому поясу из запроса (в пределах реальных поясов). Сменой пояса можно один раз выиграть лишний день стрика, но не больше.
- `/setup` и `/health` открыты без входа: первый только повторяет уже заданную настройку бота, второй показывает название канала и адрес приложения. Секретов они не возвращают.

Проверка серверной функции без сети — поддельные база и Telegram, настоящая подпись:

```bash
npm run test:api
```

Нужен Node 24. Проверяются вход, права, закрытые уроки, счёт, оплата, повторные уведомления, сбои базы и возврат.

## Запуск локально

```bash
npm install
npm run dev
```

Вне Telegram приложение открывается в демо-режиме: данные лежат в `localStorage`, к базе оно не обращается.
На проде демо доступно по адресу `/?demo`.

## Секреты

Единственный секрет — токен бота. Он хранится в Supabase → Edge Functions → Secrets под именем `BOT_TOKEN`.
В репозитории и во фронтенде его нет.

## Первый запуск

1. Добавить `BOT_TOKEN` в секреты Edge Functions.
2. Записать адрес приложения в таблицу `settings` (ключ `app_url`).
3. Открыть `…/functions/v1/api/setup` — ставит вебхук, кнопку меню и команду `/start`.
4. Добавить бота администратором в канал. Канал привяжется сам, статус виден на `…/functions/v1/api/health`.

## Контент

Урок — Markdown, сторис — слайды через строку `---`.
Кнопка «Анонсировать в канале» отправляет пост со ссылкой на урок.

В ленте материал выглядит как пост: тема, заголовок, пара строк и обложка, если она задана в редакторе.
Стартовый каталог (64 материала и курс) собирается из `content/elaz-ed-2026-10/` — см. README в этой папке.

## Код интерфейса

- `src/screens/Home.tsx` — главная; её части лежат в `src/screens/home/`: бонус дня и стрик, карусель «В фокусе», лента.
- `src/screens/Admin.tsx` — список материалов, `AdminEditor.tsx` — редактор урока и сторис.
- `src/ui.tsx` — общие компоненты, `src/index.css` — цвета и темы: менять их только через переменные.

## Админка

Доступна только аккаунтам из настройки `admins` в таблице `settings`: сейчас это `@elazart` и `@elazartist`.
При первом входе username привязывается к Telegram ID — если его потом займёт другой человек, прав он не получит.
Чтобы добавить или убрать админа, поправь JSON в этой строке (ключ — username в нижнем регистре, значение `null` до первого входа).

## Аналитика

Своя, без сторонних сервисов: события пишутся в таблицу `events`, сводку считает функция `analytics_summary`.

| Событие | Когда пишется |
| --- | --- |
| `open`, `gate` | вход в приложение; упёрся в экран подписки |
| `lesson_open`, `lesson_done` | открыл урок; прошёл (счёт квиза и ответы — в `props`) |
| `story_open`, `story_done` | открыл сторис; досмотрел |
| `daily`, `like`, `copy` | бонус дня; лайк; «Скопировать для нейронки» |
| `share` | поделился: `kind` — чем, `channel` — куда |
| `referral`, `theme` | пришёл по приглашению; сменил тему |
| `course_request`, `invoice` | попросил доступ к курсу; открыл счёт в звёздах |
| `purchase`, `refund` | оплатил курс; звёзды вернули |
| `lab` | попробовал пример в «Лаборатории» |

Экран «Аналитика» в админке показывает активность по дням, возврат на 1-й и 7-й день, воронку, статистику уроков и то, чем делятся.

## Закрытые курсы

Курс — набор уроков со своей страницей. Уроки курса не попадают в общую ленту; урок с пометкой «Открыт всем» читается без доступа.

Открыть курс можно четырьмя способами:

| Способ | Как работает |
| --- | --- |
| Звёзды Telegram | Сервер создаёт счёт (`createInvoiceLink`, валюта `XTR`), приложение открывает его поверх себя. Доступ выдаёт вебхук по событию `successful_payment`; оплата пишется в таблицу `payments`. |
| Заявка | Только у курсов без цены. Человек жмёт «Запросить доступ», админам приходит сообщение от бота с кнопками «Открыть доступ» и «Отклонить». То же самое — в админке, раздел «Курсы и заявки». Пока заявка не разобрана, повторное нажатие админам не пишет. |
| Вручную | В редакторе курса: поле «Выдать доступ» по `@username`. Человек должен хотя бы раз открыть приложение. |
| С друзьями | Если у курса задано «Открыть за друзей», он открывается сам, когда человек привёл столько людей по своей ссылке. |

Вопросы по оплате бот принимает командой `/paysupport`. Чтобы работало «Отправить в чат» с картинкой и кнопкой, у бота в @BotFather должен быть включён Inline Mode.

### Как сделать курс платным

Админка → «Курсы и заявки» → курс → «Цена в звёздах» → «Сохранить». С ценой больше нуля на странице курса появляется кнопка «Открыть за ⭐», а «Запросить доступ» пропадает: бесплатной заявки рядом с ценой нет. Ноль возвращает курс к доступу по заявке. Вручную по `@username` доступ можно выдать в любом случае.

Курс «Ролики с ИИ» стоит 250 звёзд (выложено 14 октября 2026); вводный урок «Как агент собирает ролик» открыт всем подписчикам. Подробности публикации — в `content/elaz-ed-2026-10/README.md`.

### Возврат

Админка → «Курсы и заявки» → «Покупки» → «Вернуть». Звёзды возвращает сам Telegram (`refundStarPayment`), доступ за эту оплату закрывается, покупателю приходит сообщение. Доступ, выданный вручную или по заявке, возврат не трогает. В выручку в «Аналитике» возвращённые оплаты не входят.

Если Telegram не смог доставить уведомление об оплате или база в этот момент не ответила, сервер отвечает ошибкой и Telegram присылает уведомление повторно — оплата не теряется, а дважды не засчитывается.

## Лаборатория

Экран в профиле с живыми примерами возможностей Telegram: вибро-отклик, гироскоп, акселерометр, сканер QR, биометрия, системные окна, главная кнопка, полный экран, иконка на экране телефона, облачное хранилище, сторис и звёзды. Код — `src/screens/Lab.tsx`.

## Картинки для сторис

Картинка 1080×1920 рисуется на canvas в приложении (`src/lib/shareCard.ts`): уровень, пройденный урок, стрик, ачивка.
Способы отправки зависят от устройства: системное «Поделиться» (там есть Instagram), сторис Telegram, сохранение в галерею, ссылка.
Для сторис Telegram и сохранения картинка загружается в публичное хранилище `shares` — по одному файлу на вид карточки у пользователя.

## Правила игры

- Урок: XP из карточки урока. Квиз: 10 XP за верный ответ, второй подряд — 15, дальше по 20.
- Бонус дня: `10 + 5 × min(стрик, 7)`. Стрик растёт, если бонус забран вчера и сегодня.
- Заморозка: выдаётся за каждые 7 дней стрика подряд (не больше двух) и спасает один пропущенный день.
- Приглашение: +100 XP пригласившему и +50 новичку, когда новичок прошёл проверку подписки.

Формулы продублированы в `src/lib/game.ts` и в Edge Function — менять в обоих местах.
