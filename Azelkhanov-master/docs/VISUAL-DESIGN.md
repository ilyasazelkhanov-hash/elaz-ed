# Визуальная система: мобильное приложение

Референс — исходный OG CRE8R², а не ранее добавленная копия platform-kit. Участник получает компактный интерфейс шириной до 480px и на компьютере. Управление сохраняет широкую рабочую область.

## Фирменный стиль OG

С 21 октября 2026 мастер по умолчанию выглядит как OG CRE8R²: тёмный фиолетовый фон, аврора-градиент (фиолетовый → сиреневый → розовый), сетка точек с зерном и двумя медленными пятнами, стеклянная нижняя панель-«таблетка», объёмные кнопки с проседающей нижней гранью, кольца сторис в цветах авроры, тёплая карточка бонуса дня. Слой лежит в `src/signature.css` и подключается после `src/experience.css`.

- Цвета слоя выводятся только из бренд-токенов: `colors.gradientFrom/Via/To` (аврора), `primary`, `accent`, `peach`, `dark.primary/accent`. Без градиента аврора строится из `primary` и `accent`, поэтому любой брендбук заказчика получает тот же характер в своих цветах.
- Смысловые цвета ответов (верно/неверно) заданы в слое отдельно и не зависят от бренда.
- Рабочая область управления (`.az-management`) остаётся спокойной: без фона и аркадных кнопок.
- Фон без blur-фильтров; при reduced motion сетка, пятна и блики останавливаются.

## Правила

- Сначала полезное действие: прогресс, бонус дня, контент. Один акцентный баннер вместо набора рекламных блоков.
- Unbounded для коротких заголовков, Onest для текста и управления. Не сжимать длинный текст ради сохранения карточки.
- Спокойные поверхности, тонкая граница, крупные зоны касания. Цвет помогает различать действия и состояния.
- Тёмная тема по умолчанию задана `BrandConfig.defaultTheme`; сохранённый выбор участника имеет приоритет. Светлая тема полноценна.
- Цвета, логотипы, радиусы и шрифты берутся из бренд-пакета. Состав и порядок главной — из app config. Публичные экраны оформляются в `src/experience.css`; структурные стили и административные компоненты — в `src/styles.css`.
- Движение сопровождает действие: нажатие, переворот карточки, вращение колеса, открытие награды. Автоматическое вращение декоративных звёзд не использовать.
- Нижняя панель показывает подпись выбранного раздела, остальные — иконкой. Каждый пункт обязательно сохраняет `aria-label` и область касания.

## Игры

Колесо: единая SVG-система 320×320; секторы, значки и подписи масштабируются вместе. Указатель и центральный логотип неподвижны. Конечный угол совпадает с центром выбранного сектора. Номера секторов декоративны и не обещают выдуманные призы; фактическую награду определяет сервер. Уменьшение анимации сокращает вращение.

Скретч: открытие определяется долей уникальной площади, а не длиной движения в одном месте. Есть альтернатива жесту. Пары: отдельные лицевая и обратная стороны с `backface-visibility`, без зеркальных букв. Реакция: раннее нажатие, ожидание и сигнал различаются и цветом, и текстом. Аркада: явная активная ячейка и крупная цель под палец.

Пары размещаются сеткой 4×3, чтобы все двенадцать карточек помещались на телефоне. Результат завершённой игры прокручивается выше нижней панели с учётом safe area; скретч не прокручивается во время активного стирания.

Проверки: `npm test`, `npm run build`, `npm run test:ui`, `npm run test:touch`, `npm run test:games`. Браузерным сценариям нужен dev-сервер на 5180. Изображения и машинные протоколы появляются в `test-results/`.
